# 短尺動画テロップ台本（リール／TikTok／Shorts 共通）

顔出し・声出しなしで成立する構成。**テロップ＋BGM＋画面録画**のみ。

- 出力先: Instagramリール / TikTok / YouTube Shorts（同じ動画を3箇所へ個別アップ）
- 比率: 9:16（縦）
- 尺: 20〜30秒
- 素材: 作品のプレイ画面録画 ＋ 講師コメント（PPTX「ブロマス作品集」より）＋ 教材テキスト

---

## 制作の前提（毎回共通）

### テロップは手入力（コピペ）

CapCutの「自動キャプション」は**喋っている音声を文字起こしする機能**なので、無音動画では働かない。
本ファイルのテロップをコピーして貼る前提。テキストのアニメーションはCapCutのテンプレートを使えばよい。

（どうしても自動化したい場合、CapCutの「テキスト読み上げ」で音声を作ってから自動キャプションを当てる手もあるが、二度手間なので非推奨）

### 書き出し時の注意

**TikTokの透かしが入った動画をInstagramに上げるとリーチが落ちる。**
編集はCapCut等で行い、**透かしなしで書き出して各プラットフォームに個別アップロード**すること。

### 冒頭3秒がすべて

最初の3秒で離脱が決まる。**作品のいちばん動きのある瞬間から始める**。
タイトルや挨拶から入らない。

## 台本① カラフルなアスレチック（Robloxコース・小学生）

使う素材: `assets/works/colorful-obby.jpg` の作品のプレイ動画

```
0-3秒
小学生が作った
Robloxのアスレチック

3-8秒
虹色の階段
床がランダムで切り替わる

8-14秒
らせん状のアーチ
※回転する足場を映す

14-24秒
ゲーム歴20年の講師コメント：
回転する階段は方向が分からなくなるので
調整が難しい。よく作れてる。

24-30秒
さいたま・南与野で体験会やってます
プロフィールから
```

**撮影メモ**: 虹色の階段を下から見上げるアングル → らせんアーチを通過する瞬間。
プレイヤーが実際に飛び移る動きを入れる（静止した風景だけだと伸びない）。

## 台本③ Roblox Studioあるある「浮かせたら落ちた」（教材ベース）

教材 `E0-00-アスレチック_1` の「落下しちゃう。。。」のくだりを短尺化。
**Roblox Studioを触ったことがある層（＝中高生）に刺さる**。作品が不要なので単独で作れる。

```
0-3秒
Robloxで足場を浮かせたのに
落ちるんだけど

3-8秒
※パーツを空中に置く → プレイ → 落下する様子

8-14秒
Robloxにも重力があります

14-22秒
Anchor（固定）にチェックを入れる
※プロパティのAnchorにチェックする画面

22-27秒
落ちなくなった
※もう一度プレイして浮いたままの様子

27-30秒
体験会で最初にやるところです
```

**撮影メモ**: 画面録画のみで完結。所要5分。**まずこれ1本を作るのがおすすめ**（作品の撮影待ちが不要なため）。

## 台本④ チーターマンの28M競歩（AIコース・小2）

使う素材: `assets/works/cheetah.jpg` の作品のプレイ動画

