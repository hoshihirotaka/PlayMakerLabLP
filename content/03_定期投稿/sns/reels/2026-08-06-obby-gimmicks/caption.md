# リール｜OBBY講座：ギミックの中身を見せる

- **動画**: 1080×1920 / **36秒** / Camtasiaで収録
- **構成**: プレイ映像の合間に、各ギミックのスクリプトを挟む
- **元教材**: `M1-01-Obby`（curriculumリポジトリ）koma-09〜14
- **テロップ**: [subtitle.srt](subtitle.srt) をCapCutにインポート（9カット）
- **位置づけ**: 講座シリーズ（セクション1〜3）とは別ライン。**リーチを取るための短尺**

## 投稿キャプション

```
教材で作ったアスレチックを、通しで遊んでみました。

見た目は単純ですが、床の1枚1枚がプログラミングで動いています。

・回転する床 … 向きを少しずつ足し続ける
・点滅する床 … 透明度と当たり判定を切り替える
・ダメージ床 … 触れたらHPを減らす
・動く床 … 位置を往復させる
・伸び縮みする床 … サイズを変え続ける

実はこの中に、まだ紹介していないギミックも潜んでいます。お楽しみに。

続きは体験会の先で。さいたま市南与野で開催中。
日程はプロフィールのリンクから。
```

## これまでのリールとの違い

<!-- 数値はNotionの「Instagramリールの実績と分析」を参照。ここには書かない -->

- **36秒。** 講座シリーズは58秒・92秒・90秒だったので、大幅に短い
- **静止ゼロ。** 3秒以上止まる区間が1つもない。セクション2は51%が静止していた
- **スクリプトと実演が交互。** 「コードを見せる → 実際に動く」の往復が続くので、次が気になる構造になっている
- **結末がある。** ゴール到達で終わるので、最後まで見る理由が生まれる

講座シリーズが「流れを知ってもらう」役割なのに対し、こちらは**リーチを取る役割**。狙いが違うので、指標も分けて見る。

## 書き方の意図

- **「実はまだ他にもギミックが潜んでいます」で締めた。** すべて見せきらないことで、体験会や次の動画への引きを残す
- スクリプトの説明は**1行に圧縮**（「向きを少しずつ足し続けるだけ」）。コードを読ませるのではなく、**仕組みの直感**を渡す
- 冒頭に「教材で作った」と置くことで、**教室で何が作れるかの証明**として機能させる

## 次回への申し送り

- **この形式が今のところ最良。** 短尺・静止なし・結末あり。次も同じ型で作る
- 冒頭にタイトルカードがない。講座シリーズで離脱の原因になっていた要素を外せている
- 未紹介のギミック（チェックポイント、テレポート、ジャンプ力アップ、エフェクト、ゴールの紙吹雪）が残っている。**続編の素材になる**
