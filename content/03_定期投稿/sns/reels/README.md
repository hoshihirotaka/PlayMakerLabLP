# reels/ — 制作・投稿した短尺動画

Instagramリール／TikTok／YouTube Shorts に実際に出した動画の、**テロップと投稿文をセットで**残す場所。

企画段階の台本は [reels-作品講評-台本.md](../reels-作品講評-台本.md) と [reels-srt/](../reels-srt/) にある。
こちらは**作り終えたもの**を1本1フォルダで置く。

## フォルダ構成

```
reels/
└── YYYY-MM-DD-{英数字のスラッグ}/
    ├── caption.md    投稿キャプション＋制作メモ＋反省
    └── subtitle.srt  テロップ（CapCut/Camtasiaにインポート）
```

## 置いてあるもの

| フォルダ | 内容 | 投稿日 |
|---|---|---|
| `2026-08-05-roblox-studio-basics` | Roblox Studioの最初の一歩（58秒） | 2026-08-05 |

## ルール

- **動画ファイル本体は置かない。** 数十MB〜になるためリポジトリが膨らむ。書き出し済みの動画は各自の手元かクラウドで保管する
- `caption.md` には**投稿後に確認する指標**と**次回への申し送り**を書く。同じ失敗を繰り返さないための記録
- キャプションはタグ5個まで・本文500文字以内（Threads同時投稿の制約）
- 共通ルールは [SNS-GUIDE.md](../../../04_共通/SNS-GUIDE.md) を参照
