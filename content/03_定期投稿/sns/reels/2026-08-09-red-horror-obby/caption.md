## 動画の解析

### 静止区間（freezedetect / n=-50dB, d=1.5）

| 区間 | 長さ | 内容 |
|---|---|---|
| **49.7 – 51.4秒** | 1.67秒 | FINISHの門を映したままカメラが止まる |

**静止はここ1か所だけ。** SRTの11番（47.0–52.0）でカバーしてある。
リールとしては十分に動いている素材。冒頭0秒からプレイ画面が動いていて、タイトルカードもない（＝離脱の主因を踏んでいない）。

### 構成

| 秒 | 内容 |
|---|---|
| 0–4 | 虹色の階段の上。リスポーン直後（フォースフィールドの球）。空は一面まっ赤 |
| 4–8 | 赤白ストライプの一本道。**赤い部分が発光＝当たると死ぬ**。転倒 |
| 8–13 | 水色の細い一本道。足場がさらに狭くなる |
| 13–17 | 落下 → リスポーン |
| 17–21 | 白い足場のジャンプ区間。床に**星マーク（チェックポイント）** |
| 21–26 | **赤い床＋灰色の円柱。** 円柱だけを踏んで渡る区間 |
| 26–32 | 落下 → リスポーン |
| 32–39 | 虹色の階段／カラフルな細いバーを飛び移る |
| 39–42 | 落下 |
| 42–50 | カメラが引いてコース全景。虹色の螺旋階段、**緑のSTART看板**、**FINISHのチェッカー旗と緑のガラス門** |
| 50–61 | 最後の虹色トンネル。赤く光るブロックを避けて進む |

### 気づいたこと・申し送り

- **ゴールに到達しないまま終わる。** OBBY講座36秒で効いた「結末がある」型を外している。ここは弱点だが、LPの講師コメントにある「近道」を最後の引きに使って埋めた（SRT 13番）。**ゴール到達のカットが撮れるなら、差し替えると型が完成する**
- **音声トラックなし。** Instagram側でBGMを付ける前提
- 60.8秒は作品紹介ラインとしては長め。**リーチを取りにいくなら35〜40秒に詰める**価値がある。切るなら 8–13秒（水色の道）と 32–39秒（虹色バー）が候補。42–50秒の全景は「これ全部手作り」が伝わる箇所なので残す
- 日本語テロップは必須。Robloxの画面は言語シグナルがほぼゼロで、入れないと海外に流れる（[REEL-WORKFLOW.md](../../../04_共通/REEL-WORKFLOW.md)）
- プレイしているのが先生か本人か、動画からは断定できない。キャプションはLPの講師コメント（「先生も何度もやられました」）に合わせてある。**違っていたら2行目を直す**
