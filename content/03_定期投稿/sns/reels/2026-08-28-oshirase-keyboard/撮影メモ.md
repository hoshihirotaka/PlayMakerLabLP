## プランは2段構え

**看板はどちらでも使う。先に建てておけば無駄にならない。**

| | 尺 | 中身 | 判断 |
|---|---|---|---|
| **B（確実）** | 10秒前後 | 看板だけ。8/9の「お知らせ」回と同じ作り | まずこれを出せる状態にする |
| **A（狙い）** | 30秒 | キーボードランの実演 → 最後に看板 | 撮影と編集に余裕があれば |

**夕方までにAが撮れなければBを出す。** Bの素材はAの最終カットそのもの。

## 1. 8/28告知看板を建てる（コマンドバーに貼る）

**縦長14×20。** 9:16の画面に横長看板（24×13.5）は収まらず、8/9の初回は全カットで文字が見切れた。

```lua
-- 8/28 告知看板を建てる（Studioのコマンドバーに貼って実行）
local ws = workspace
local old = ws:FindFirstChild("Sign_0828")
if old then old:Destroy() end

local f = Instance.new("Folder")
f.Name = "Sign_0828"
f.Parent = ws

local POS = Vector3.new(0, 12, -30)   -- ← 立てる場所。表は -Z 側を向く

-- 板本体（縦長 14 × 20）
local board = Instance.new("Part")
board.Name = "Board"
board.Anchored = true
board.CanCollide = false
board.Size = Vector3.new(14, 20, 1)
board.Position = POS
board.Color = Color3.fromRGB(18, 18, 24)
board.Material = Enum.Material.SmoothPlastic
board.Parent = f

-- 背後のネオン（暗い空間に光源だけ灯っているほうが動画向き）
local glow = Instance.new("Part")
glow.Name = "Glow"
glow.Anchored = true
glow.CanCollide = false
glow.Size = Vector3.new(15.2, 21.2, 0.6)
glow.Position = POS + Vector3.new(0, 0, 0.5)
glow.Color = Color3.fromRGB(120, 230, 255)
glow.Material = Enum.Material.Neon
glow.Parent = f

local light = Instance.new("PointLight")
light.Brightness = 1.2
light.Range = 40
light.Color = Color3.fromRGB(160, 220, 255)
light.Parent = board

local gui = Instance.new("SurfaceGui")
gui.Face = Enum.NormalId.Front   -- Front は -Z 側
gui.PixelsPerStud = 40
gui.Parent = board

local bg = Instance.new("Frame")
bg.Size = UDim2.fromScale(1, 1)
bg.BackgroundColor3 = Color3.fromRGB(18, 18, 24)
bg.BorderSizePixel = 0
bg.Parent = gui

local function label(text, yScale, hScale, color, font)
	local t = Instance.new("TextLabel")
	t.Size = UDim2.fromScale(0.86, hScale)
	t.Position = UDim2.fromScale(0.07, yScale)
	t.BackgroundTransparency = 1
	t.Text = text
	t.TextScaled = true
	t.TextColor3 = color
	t.Font = font
	t.Parent = bg
end

local W = Color3.fromRGB(255, 255, 255)
local C = Color3.fromRGB(120, 230, 255)
local Y = Color3.fromRGB(255, 210,  90)

label("ゲームクリエイター", 0.09, 0.09, W, Enum.Font.GothamBold)
label("体験会",             0.19, 0.14, W, Enum.Font.GothamBlack)
label("8/28(金)",           0.42, 0.15, C, Enum.Font.GothamBlack)
label("南与野",             0.60, 0.09, W, Enum.Font.GothamBold)
label("Roblox / AI",        0.76, 0.08, Y, Enum.Font.GothamBold)

print("Sign_0828 を建てました。表は -Z 側を向いています")
```

### 看板に載せる情報を絞っている理由

**動画は1メッセージしか運べない。** 8/9の反省がこれ。
時間・料金・対象・持ち物は**看板に載せず、テロップとキャプションに回す**。看板は雰囲気として置く。

| 看板に載せる | テロップ／キャプションに回す |
|---|---|
| ゲームクリエイター体験会 | 時間（17:00-20:30） |
| 8/28(金) | 料金（900円 / 1,900円） |
| 南与野 | 対象（小1〜高校生） |
| Roblox / AI | 会場名・住所・申込URL |

> ⚠️ **半角の `()` を使うこと。** 全角「（）」は前に余白が入って間延びする（8/9検証）。
> フォントを変えても和文の書体はほぼ変わらない。変わるのは**太さと実寸だけ**。

## 2. 収録用スクリプト（撮影のたびに使う）

`StarterPlayer > StarterPlayerScripts` に **LocalScript** として入れる。
**これがないと、カーソル・Robloxメニュー・手ブレで撮り直しになる。**

```lua
-- 撮影用（StarterPlayer > StarterPlayerScripts の LocalScript）
local TweenService = game:GetService("TweenService")
local UserInputService = game:GetService("UserInputService")
local StarterGui = game:GetService("StarterGui")

local camera = workspace.CurrentCamera

-- 画面に余計なものを写さない
UserInputService.MouseIconEnabled = false
pcall(function() StarterGui:SetCoreGuiEnabled(Enum.CoreGuiType.All, false) end)
pcall(function() StarterGui:SetCore("TopbarEnabled", false) end)

task.wait(1)

--------------------------------------------------------------------
-- ここを撮りたい対象に合わせて変える
--------------------------------------------------------------------
local TARGET = workspace:WaitForChild("Sign_0828"):WaitForChild("Board")

local FROM    = TARGET.Position + Vector3.new(-16, 10, -38)  -- 引き・斜め
local TO      = TARGET.Position + Vector3.new(  0,  1, -17)  -- 寄り・正面
local SECONDS = 7
--------------------------------------------------------------------

camera.CameraType = Enum.CameraType.Scriptable
camera.CFrame = CFrame.new(FROM, TARGET.Position)

task.wait(0.5)

TweenService:Create(
	camera,
	TweenInfo.new(SECONDS, Enum.EasingStyle.Sine, Enum.EasingDirection.InOut),
	{ CFrame = CFrame.new(TO, TARGET.Position) }
):Play()
```

### キーボードランを撮るときの差し替え

`TARGET` と `FROM` / `TO` を変えるだけ。走っている自分を追う場合は、
`camera.CameraType` を触らず（既定のまま）、CoreGui消しとカーソル消しだけ使う。

```lua
-- 走りを撮るとき：カメラは自動追従のまま、余計なUIだけ消す
-- （上の TARGET 以降をコメントアウトする）
```

> 💡 **CFrame の Tween を使う理由**：マウスに触らずカメラが動くので、**手ブレとカーソル写り込みが同時に解決する**。

## 3. 絵コンテ

### プランB（10秒・確実に出せる版）

```
0-2s   看板が画面いっぱい（すでに寄っている状態から始める）
       大テロップ「Robloxの中に看板を立ててみた」
2-6s   カメラが引く。暗い空間にネオンだけ光っている
       テロップ「8/28(金) 南与野」
6-10s  テロップ「遊ぶ側から、作る側へ」
       末尾「日程はプロフィールから」
```

**短くてもいい。** リールは自動ループするので2周目で読み切れる。完走率の面ではむしろ有利（8/9・3.3秒の実績）。

### プランA（30秒・狙い版）

```
0-2s   すでに全速力でキーボードの上を走っている（タイトルカードなし）
       大テロップ「キーボードの上、走れます」
2-8s   画面の数字が増えていく → 倍率床を踏む → 明らかに加速
8-16s  さっき届かなかった谷を跳ぶ → 着地
16-24s さらに奥へ。数字が跳ね上がる
24-28s 走り抜けた先に 8/28 の看板
28-30s 「日程はプロフィールから」
```

**冒頭の順番を守る。** 説明は「見る理由」が成立してから。
スライドやタイトルカードで始めると、冒頭で大半が離脱する（複数本で計測済み）。

## 4. 撮影チェックリスト

書き出す前に**5項目すべてに○**が付く状態にする。

- [ ] **タイトルカードを入れていない。** 0秒目から画面が動いている
- [ ] **冒頭1〜2秒に、大きな日本語テキストがある**（国内配信の担保とフックを兼ねる）
- [ ] **尺が30秒以内**
- [ ] **静止区間がゼロ**
- [ ] **末尾に1アクションがある**（「日程はプロフィールから」）

### 収録時の実務

| 症状 | 対処 |
|---|---|
| Studioのツールバーが写る | フルスクリーンで再生、または `Cmd+Shift+5` でビューポートだけ範囲指定 |
| マウスカーソルが写る | 上の収録用スクリプト（`MouseIconEnabled = false`） |
| 左上にRobloxメニュー | 同スクリプトの `SetCoreGuiEnabled` / `TopbarEnabled` |
| 手ブレする | カメラを手で動かさない。TweenServiceに任せる |
| 看板の文字が読めない | **情報はテロップへ。看板は雰囲気として置く** |

### テロップの設計

**看板に書いてあることをテロップで繰り返さない。看板が言えないことに使う。**

8/9は1枚目が看板と重複していた（「ゲームクリエイター体験会」）。
今回は1枚目を **「Robloxの中に看板を立ててみた」** にして、
**この動画自体がRobloxで作られていることを冒頭で伝える**。

日本語2行は**最低2秒**。3枚入れるなら尺は6〜8秒欲しい。
