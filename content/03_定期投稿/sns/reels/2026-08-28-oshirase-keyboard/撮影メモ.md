**看板はどちらでも使う。先に建てておけば無駄にならない。**

| | 尺 | 中身 | 判断 |
|---|---|---|---|
| **B（確実）** | 10秒前後 | 看板だけ。8/9の「お知らせ」回と同じ作り | まずこれを出せる状態にする |
| **A（狙い）** | 30秒 | キーボードランの実演 → 最後に看板 | 撮影と編集に余裕があれば |

**夕方までにAが撮れなければBを出す。** Bの素材はAの最終カットそのもの。

## 0. キーボード走路を作る（最初にこれ）

### なぜ必要か（2026-08-21 実測）

キットは **6色のキーボードがバラバラに置かれた見本市**だった。1枚あたり数十スタッドしかない。

| | 実測値 |
|---|---|
| キー1個 | 3 × 1.37 × 3スタッド（上面 y ≈ 2.4） |
| `Themes.Plain` | x ≈ -1.4 ／ z ≈ 37〜44 |
| `Themes["Dark rainbow"]` | x ≈ 55.6 ／ z ≈ 64.8（別の場所） |
| `Misc` | x ≈ -30 ／ z ≈ 101（さらに別の場所） |

速さ40〜80で30秒走ると **300〜600スタッド**要る。**そのままでは数秒で端に着く。**

### 6枚を一直線に並べる

**走るうちに足元の色が変わる**ので、画に変化が出て静止感が消える。並べる長さは
スクリプトが実行時に測るので、座標を手で調べる必要はない。

```lua
-- キーボード走路を作る（Studioのコマンドバーに貼って実行）
-- 6テーマを -Z 方向へ一直線に並べ、終点に 8/28 看板を立てる
local ws = workspace
local kit = ws:WaitForChild("Model"):WaitForChild("Clicky Keyboard Asmr")
local themes = kit:WaitForChild("Themes")

local GAP = 3        -- キーボード同士のすきま
local SIGN_BACK = 40 -- 走路の終点から看板までの距離

-- 中身の BasePart から範囲を求める
local function bounds(inst)
	local lo, hi
	for _, d in ipairs(inst:GetDescendants()) do
		if d:IsA("BasePart") then
			local a = d.Position - d.Size / 2
			local b = d.Position + d.Size / 2
			if not lo then
				lo, hi = a, b
			else
				lo = Vector3.new(math.min(lo.X,a.X), math.min(lo.Y,a.Y), math.min(lo.Z,a.Z))
				hi = Vector3.new(math.max(hi.X,b.X), math.max(hi.Y,b.Y), math.max(hi.Z,b.Z))
			end
		end
	end
	return lo, hi
end

local function move(inst, delta)
	for _, d in ipairs(inst:GetDescendants()) do
		if d:IsA("BasePart") then d.Position = d.Position + delta end
	end
end

local root = ws:FindFirstChild("キーボード走路")
if root then root:Destroy() end
root = Instance.new("Folder")
root.Name = "キーボード走路"
root.Parent = ws

local z = 0          -- 手前端。ここから -Z へ伸ばす
local topY = 0
for _, theme in ipairs(themes:GetChildren()) do
	local lo, hi = bounds(theme)
	if lo then
		local size = hi - lo
		local center = (lo + hi) / 2
		-- 中心を (0, 高さそのまま, z - 奥行/2) へ
		move(theme, Vector3.new(0, 0, z - size.Z / 2) - Vector3.new(center.X, 0, center.Z))
		theme.Parent = root
		z = z - size.Z - GAP
		topY = math.max(topY, hi.Y)
	end
end

local LENGTH = math.abs(z)
print(("走路の長さ: %d スタッド"):format(LENGTH))
print(("速さ40なら約%.1f秒 / 速さ80なら約%.1f秒で走り切る"):format(LENGTH/40, LENGTH/80))

--------------------------------------------------------------------
-- 8/28 告知看板（走ってくる側＝+Z を向く）
--------------------------------------------------------------------
local o = ws:FindFirstChild("BromasSign_0828") if o then o:Destroy() end
local f = Instance.new("Folder") f.Name = "BromasSign_0828" f.Parent = ws
local b = Instance.new("Part") b.Name = "Board" b.Anchored = true b.CanCollide = false
b.Size = Vector3.new(14,20,0.6) b.CFrame = CFrame.new(0, topY + 10, z - SIGN_BACK)
b.Material = Enum.Material.SmoothPlastic b.Color = Color3.fromRGB(10,16,34) b.Parent = f
local g = Instance.new("SurfaceGui") g.Face = Enum.NormalId.Back g.PixelsPerStud = 50
g.LightInfluence = 0 g.Parent = b
local function line(t,sz,y,h,c)
  local l = Instance.new("TextLabel") l.BackgroundTransparency = 1
  l.Size = UDim2.new(1,0,h,0) l.Position = UDim2.new(0,0,y,0)
  l.Font = Enum.Font.GothamBold l.TextSize = sz l.TextColor3 = c
  l.TextStrokeTransparency = 0.7 l.Text = t l.Parent = g
end
local W,O = Color3.fromRGB(255,255,255), Color3.fromRGB(255,122,60)
line("ブロマス",           58,0.04,0.08,O)
line("ゲームクリエイター",  46,0.13,0.07,W)
line("体験会",             80,0.21,0.10,W)
line("8/28",              200,0.34,0.20,W)
line("(金)",              100,0.55,0.09,W)
line("17:00-20:30",        88,0.66,0.09,W)
line("路地裏",             52,0.79,0.07,O)
line("GarageMarket",       52,0.86,0.07,O)

-- スタート地点を走路の手前へ
local spawn = ws:FindFirstChildOfClass("SpawnLocation")
if spawn then
	spawn.Anchored = true
	spawn.Position = Vector3.new(0, topY + 1, 12)
end

print(("看板: z = %d / 高さ %d"):format(z - SIGN_BACK, topY + 10))
```

> ⚠️ **元のキーボードを動かす**（複製ではない）。パーツ数が増えないので軽いまま。
> 見本市の並びに戻したいときは **Ctrl+Z**。

### 走り切る時間が足りないとき

`print` が出す「走路の長さ」を見て判断する。

| 長さ | どうするか |
|---|---|
| 300スタッド以上 | そのままでOK |
| 足りない | `Misc` も並べる／同じテーマをもう1周コピーして足す |
| 長すぎる | 撮影で途中まで走ればよい。**削らない** |

## 1. 看板だけを建てる場合（プランB・走路なし）

**[8/9の看板スクリプト](../2026-08-09-oshirase/caption.md)を流用。** 日付・曜日・時間だけ差し替えた。
実写で検証済みの作りなので、構造には手を入れない。

```lua
local ws = workspace
local o = ws:FindFirstChild("BromasSign_0828") if o then o:Destroy() end
local f = Instance.new("Folder") f.Name = "BromasSign_0828" f.Parent = ws
local b = Instance.new("Part") b.Name = "Board" b.Anchored = true b.CanCollide = false
b.Size = Vector3.new(14,20,0.6) b.CFrame = CFrame.new(0,15,0)
b.Material = Enum.Material.SmoothPlastic b.Color = Color3.fromRGB(10,16,34) b.Parent = f
local g = Instance.new("SurfaceGui") g.Face = Enum.NormalId.Back g.PixelsPerStud = 50
g.LightInfluence = 0 g.Parent = b
local function line(t,s,y,h,c)
  local l = Instance.new("TextLabel") l.BackgroundTransparency = 1
  l.Size = UDim2.new(1,0,h,0) l.Position = UDim2.new(0,0,y,0)
  l.Font = Enum.Font.GothamBold l.TextSize = s l.TextColor3 = c
  l.TextStrokeTransparency = 0.7 l.Text = t l.Parent = g
end
local W,O = Color3.fromRGB(255,255,255), Color3.fromRGB(255,122,60)
line("ブロマス",           58,0.04,0.08,O)
line("ゲームクリエイター",  46,0.13,0.07,W)
line("体験会",             80,0.21,0.10,W)
line("8/28",              200,0.34,0.20,W)
line("(金)",              100,0.55,0.09,W)
line("17:00-20:30",        88,0.66,0.09,W)
line("路地裏",             52,0.79,0.07,O)
line("GarageMarket",       52,0.86,0.07,O)
```

### 8/9から変えたところ

| | 8/9 | 8/28 | 理由 |
|---|---|---|---|
| 日付 | `8/9` TextSize **230** | `8/28` TextSize **200** | 1文字増えたので下げた。**収まるなら230のままのほうが強い**ので、撮る前に見て調整 |
| 曜日 | `(日)` | `(金)` | |
| 時間 | `11:00-17:00` | `17:00-20:30` | 桁数が同じなのでサイズ据え置き |
| 会場 | 路地裏GarageMarket | 同じ | 変更なし |

### この作りで効いているところ（触らないこと）

| | なぜ必要か |
|---|---|
| `g.LightInfluence = 0` | **暗いシーンでも文字が沈まない。** 今回は照明を落として撮るので必須 |
| `TextStrokeTransparency = 0.7` | 縁取り。背景に負けない |
| `TextSize` を行ごとに指定 | `TextScaled` だと日付を巨大にする階層が作れない |
| オレンジ `(255,122,60)` | **ブロマスのブランドカラー。** 勝手に変えない |
| `Face = Back` | 実写で確認済みの向き |
| 半角 `()` | 全角「（）」は前に余白が入って間延びする（8/9検証） |

### 看板に載せる情報を絞っている理由

**動画は1メッセージしか運べない。** 時間より下は雰囲気として置いているだけ。
料金・対象・持ち物・申込URLは**テロップとキャプションに回す**。

> ⚠️ フォントを変えても和文の書体はほぼ変わらない。変わるのは**太さと実寸だけ**。
> 日本語を持たないフォントは代替に落ちるため、欧文だけが変化する（8/9検証）。

## 2. 撮影用スクリプト（コマンドバーに貼ってから再生）

**これも8/9のものをそのまま使う。** カメラの寄りとエモートを自動化する。
**貼るだけで自分を `StarterPlayerScripts` に書き込む**ので、手でLocalScriptを作る必要はない。

```lua
local sp = game:GetService("StarterPlayer"):WaitForChild("StarterPlayerScripts")
local old = sp:FindFirstChild("CamShot") if old then old:Destroy() end
local s = Instance.new("LocalScript") s.Name = "CamShot" s.Parent = sp
s.Source = [==[
local TS = game:GetService("TweenService")
local UIS = game:GetService("UserInputService")
local SG = game:GetService("StarterGui")
local plr = game.Players.LocalPlayer
UIS.MouseIconEnabled = false
pcall(function() SG:SetCoreGuiEnabled(Enum.CoreGuiType.All, false) end)
pcall(function() SG:SetCore("TopbarEnabled", false) end)
local char = plr.Character or plr.CharacterAdded:Wait()
local hum = char:WaitForChild("Humanoid")
local cam = workspace.CurrentCamera
cam.CameraType = Enum.CameraType.Scriptable
cam.FieldOfView = 60
local target = Vector3.new(0, 15, 0)
cam.CFrame = CFrame.lookAt(Vector3.new(0, 19, 46), target)
task.wait(1)
TS:Create(cam, TweenInfo.new(8, Enum.EasingStyle.Sine, Enum.EasingDirection.InOut),
  { CFrame = CFrame.lookAt(Vector3.new(0, 15.5, 24), target) }):Play()
task.wait(2)
if not pcall(function() hum:PlayEmote("wave") end) then
  local a = Instance.new("Animation") a.AnimationId = "rbxassetid://507770239"
  local ar = hum:FindFirstChildOfClass("Animator") or Instance.new("Animator", hum)
  ar:LoadAnimation(a):Play()
end
]==]
```

エモートID（R15）: wave `507770239` ／ point `507770453` ／ cheer `507770677` ／ laugh `507770818` ／ dance `507771019`

> 💡 **カメラをTweenで動かす理由**：マウスに触らないので、**手ブレとカーソル写り込みが同時に消える**。

### キーボードランを撮るとき（プランA）

看板は最後のカットなので、**走りの撮影は別テイクにする**。
上のスクリプトから `cam.CameraType` 以降を消し、UI消しの3行だけ残せば、
カメラは通常の追従のまま、余計なものだけ写らなくなる。

```lua
-- 走りを撮るとき：CamShot の中身をこれだけにする
local UIS = game:GetService("UserInputService")
local SG = game:GetService("StarterGui")
UIS.MouseIconEnabled = false
pcall(function() SG:SetCoreGuiEnabled(Enum.CoreGuiType.All, false) end)
pcall(function() SG:SetCore("TopbarEnabled", false) end)
```

> ⚠️ ただし **`SpeedGui` まで消える。** 速さの数字は今回の見せ場なので、
> `SetCoreGuiEnabled` は **CoreGui（Robloxの標準UI）だけ**を消す点を確認しておく。
> 自作の `ScreenGui` は消えない。

## 3. 照明（8/9の知見）

ツールボックスの背景を使うなら、**暗いままのほうが動画向き**。

- **全体照明（`game.Lighting`）を上げると平坦になる。** 8/9では一度上げて戻した
  （元の値: Ambient / OutdoorAmbient = 70,70,70、ExposureCompensation = 0）
- 代わりに背景側に **PointLight** を置く。強すぎると白飛びするので **Brightness 1前後・Range 40前後**
- **暗い空間に光源だけ灯っているほうが、看板のネオン感も出る**

## 4. 絵コンテ

### プランB（10秒・確実に出せる版）

```
0-2s   看板が画面いっぱい（すでに寄っている状態から始める）
       大テロップ「Robloxの中に看板を立ててみた」
2-6s   カメラが引く。暗い空間にネオンだけ光っている
       テロップ「8/28(金) 南与野」
6-10s  テロップ「遊ぶ側から、作る側へ」
       末尾「日程はプロフィールから」
```

**短くてもいい。** リールは自動ループするので2周目で読み切れる。完走率の面ではむしろ有利（8/9・3.3秒の実績）。

### プランA（30秒・狙い版）

```
0-2s   すでに全速力でキーボードの上を走っている（タイトルカードなし）
       大テロップ「キーボードの上、走れます」
2-8s   画面の数字が増えていく → 倍率床を踏む → 明らかに加速
8-16s  さっき届かなかった谷を跳ぶ → 着地
16-24s さらに奥へ。数字が跳ね上がる
24-28s 走り抜けた先に 8/28 の看板
28-30s 「日程はプロフィールから」
```

**冒頭の順番を守る。** 説明は「見る理由」が成立してから。
スライドやタイトルカードで始めると、冒頭で大半が離脱する（複数本で計測済み）。

## 5. 撮影チェックリスト

書き出す前に**5項目すべてに○**が付く状態にする。

- [ ] **タイトルカードを入れていない。** 0秒目から画面が動いている
- [ ] **冒頭1〜2秒に、大きな日本語テキストがある**（国内配信の担保とフックを兼ねる）
- [ ] **尺が30秒以内**
- [ ] **静止区間がゼロ**
- [ ] **末尾に1アクションがある**（「日程はプロフィールから」）

### 収録時の実務

| 症状 | 対処 |
|---|---|
| Studioのツールバーが写る | フルスクリーンで再生、または `Cmd+Shift+5` でビューポートだけ範囲指定 |
| マウスカーソルが写る | 上の収録用スクリプト（`MouseIconEnabled = false`） |
| 左上にRobloxメニュー | 同スクリプトの `SetCoreGuiEnabled` / `TopbarEnabled` |
| 手ブレする | カメラを手で動かさない。TweenServiceに任せる |
| 看板の文字が読めない | **情報はテロップへ。看板は雰囲気として置く** |

### テロップの設計

**看板に書いてあることをテロップで繰り返さない。看板が言えないことに使う。**

8/9は1枚目が看板と重複していた（「ゲームクリエイター体験会」）。
今回は1枚目を **「Robloxの中に看板を立ててみた」** にして、
**この動画自体がRobloxで作られていることを冒頭で伝える**。

日本語2行は**最低2秒**。3枚入れるなら尺は6〜8秒欲しい。
