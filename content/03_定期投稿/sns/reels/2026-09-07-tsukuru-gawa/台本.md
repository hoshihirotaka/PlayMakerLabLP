### ③④を分けた（2026-09-07）

**8/28の掲載許諾（アンケートQ8）の記録が見当たらない。**

> 撮影可否（同意書のチェックボックス）とは**別物**。写真がOKでも**作品は都度確認が要る**（AGENTS.md）

**8/9の許諾は8/28の作品をカバーしない。** 記録のない作品を全部下ろした判断（HANDOFF §2）と
食い違うので、ここは曲げない。

#### 代わりに、許諾済みの素材だけで組めた

**バスは `IMG_0009_emoji_ほしアレンジ.mp4` の25.0〜27.5秒**にある。
**絵文字加工済みで、教室の机の上のノートPCという文脈まで写っている。**
画面収録より、こちらのほうが「教室で作っている」が伝わる。

**結果として構成が良くなった。** ③④で「実績 → 今月の中身」の流れができ、
追加の許諾確認なしで作れる。

### ⑤は教室の引きの写真を、パンして使う（2026-09-07 決定）

**当初は `プレイ会の様子.mov` を想定したが使えない。** テロップが焼き込まれていて
「8/28（金）でもあります」と日付が入っている。元動画（`0809作品/video_*.mp4`）は
**PC画面の直撮り・横1280×720**で、**場の雰囲気が出ない。**

**代わりに教室の引きの写真を使う。** 人・机・覗き込む姿・会場の内装がすべて入っている。

#### パンがそのまま目隠しになる

```
元画像        1468 × 905（横位置）
9:16の窓      509 × 905 ＝ 全幅の35%しか映らない
パン          left 480（中央）→ 850 付近
```

**縦画面には35%しか入らないので、左側は最初から映らない。**

| | |
|---|---|
| **左奥のカフェの女性** | **完全に外れる。** 教室と無関係の第三者で、許諾を取りようがない |
| 左手前の大人 | 完全に外れる |

**⚠️ 終点を右端（959）まで行かせない。** 最後が大人の背中とポスターになって締まらない。
**850前後で止めると、覗き込んでいる場面が残ったまま終わる。**

#### 絵文字は本人以外すべてに乗せる（2026-09-07 本人判断）

```
本人（講師）      顔出しのまま。「先生はこの人です」が伝わる
それ以外          顔の一部でも見えたら絵文字
後ろ姿だけの人    不要
```

**広告に使うので基準を上げる。** 配信範囲も期間もオーガニックより広く、
**少しでも顔立ちが分かるアングルは避ける。**
風景動画と同じ絵文字を使えば、シリーズとして揃う。

**⚠️ 加工後、パンの開始・中間・終了の3フレームを書き出して目視すること。**
パンの途中でだけ顔が出る人がいると、静止画の確認では見つからない。

#### 背景の寄せ書きは問題なし

「進級おめでとう」の寄せ書きが背景に写るが、**この解像度では文字が読めない**（拡大して確認済み）。

#### パンはffmpegで作れる

```bash
cd ~/Desktop && /usr/local/bin/ffmpeg -y \
  -i "スクリーンショット 2026-09-07 10.07.34.png" \
  -vf "crop=509:905:'480+(850-480)*t/4':0,scale=1080:1920" \
  -t 4 -r 30 -pix_fmt yuv420p ~/Desktop/pan_test.mp4
```

**4秒で 480→850 までパンする。** 速度や終点は数字を変えるだけ。

##### 分担

```
ffmpeg   カット・パン・連結・尺合わせ   コマンドで確実
CapCut   絵文字とテロップ              ここだけ手作業
```

**自動化できる範囲がはっきりする。** GUI操作に頼る部分を最小にできる。

## 組み立て（2026-09-07）

### ⚠️ カードは「動く映像に重ねる」形にした

**当初は静止画にゆっくりズームをかけたが、静止区間として検出された。**
1080×1350のカードを9:16に置くと**上下に黒帯が出て、そこが画面の3割を占めて動かない。**

**9月プロモと同じ手に変えた** ── ぼかした映像の上にカードを重ねる。
**背景が動くので静止しない。** 検算も通った（最小2.27／閾値1.0）。

### 実尺 23.8秒

当初28秒で設計したが、**日程カードの7.5秒が長すぎた**（9月プロモは2秒）。
4.0秒に詰めて23.8秒になった。**30秒以内の条件は余裕を持って満たす。**
