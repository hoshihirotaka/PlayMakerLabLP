## 素材の見取り図

チャットは **10.5〜21秒に一気にスクロール**し、**21秒以降は203秒までまったく動かない**
（変化量0.08＝実質静止）。つまり使える「プロンプトの見せ場」は前半に集中している。

### プロンプトが読める区間

| 秒 | 内容 | 使い方 |
|---|---|---|
| **0–10** | **修正プロンプト**と、その返答 | ズーム①。**共有カードを切ること** |
| 10.5–13 | スクロール中（速い） | 使わない |
| **13.5–15.5** | **元のプロンプト全文**＋AIの質問 | ズーム②。全文が読める最も安定した区間 |
| 15.5–21 | スクロールが戻る | 使わない |
| 21–203 | 完成の返答＋「どうやって右左などに移動するの」で固定 | 背景として使える |

### 読み取ったチャット本文

**① 元のプロンプト（13.5–15.5秒）**

> 1か月生き残るゲームなんだけどそれで毎日ゾンビや海賊　泥棒なんかに襲われるんだから毎日支援ボックスというボックスが届いてそこから出た武器やトラップペットなどで戦うんだ家の体力や自分の体力がなくなるとゲームオーバーで家の中心にあるダイヤモンドを攻撃されると家に攻撃自分が攻撃されると自分の体力が減ってペットも攻撃されるとダメージを受けてドラゴンやユニコーン犬など空想の生き物普通の動物など色々出てくるんだ
>
> （3Dのゲームにしてください）

句読点がほとんどなく、一息で書かれている。**これが「思っていることを全部ぶつけた」状態そのもの**で、
LPの講師コメント「作りたいものを作るには、思っていることをちゃんと伝えないといけない」に行き着いた先の文章。

**② AIの折り返し質問（同区間）**

> 2Dと3D、どっちのゲームにする？　[2Dでつくる！] [3Dでつくる！]
> 最後に、どんな見え方にする？　→（選択）**斜め上から見る**

**③ 完成の返答（21秒以降ずっと）**

> 『3Dダイヤ防衛サバイバー』ができたよ！あそんでみてね！
> 1文で説明: 庭を走り回って昼に支援箱を開けて武器・罠・ペットを獲得し、夜に四方から迫るゾンビ・海賊・泥棒から家のダイヤモンドを守り抜け！

**④ 修正プロンプト（0–10秒）← 今回の主役**

> （子）毎回画面が動かすたびに移動するんだけどいどうしないようにして
>
> （AI）プレイヤーを応援しているよ！画面が動いて酔わないようにカメラの位置を固定したよ！
> 　　　変えたこと・キャラクターが移動しても画面（カメラ）が動かず中央を静止して見渡せるように固定しました

**誤字も文法の乱れもあるまま直っている**のが要点。「正しく書けないと使えない」という保護者の思い込みを崩せる。

## 「人が少ない／多い」の比較

HUDの `DAY x/30` と `撃破` を10秒ごとに読み取った結果、**昼（準備）→夜（防衛!）のサイクル**で
きれいに増えていく。比較に使うなら **DAY1の夜 と DAY9の夜** が最も差が出る。

| | **少ない（22秒）** | **多い（196秒）** |
|---|---|---|
| 表示 | DAY 1/30・夜（防衛!） | DAY 9/30・夜（防衛!） |
| 敵 | **1体** | **5体**（四方から囲む） |
| 撃破 | 1 | **49** |
| ダイヤ | 200/200（無傷） | **160/200**（削られている） |
| 右下の装備 | **1個**（伝説の剣） | **7個**（伝説の剣／爆炎の魔法杖／連射ライフル／装甲グマ／ちびドラゴン／忠犬ポチ／忠犬ポチ） |

**装備欄の1→7が一番効く。** 敵の数だけだと「難しくなった」で終わるが、装備が増えていることで
「昼に集めて夜に戦う」というゲームの設計そのものが伝わる。

さらに、**装備欄の「ちびドラゴン」「忠犬ポチ」は、元のプロンプトの「ドラゴンやユニコーン犬など空想の生き物」**。
プロンプトに書いたことが実装として返ってきている対応関係が、画面の中だけで示せる。

## 構成案（30秒以内）

[REEL-WORKFLOW.md](../../../../04_共通/REEL-WORKFLOW.md) のチェックリストに沿う。
**タイトルカードなし・0秒目から動いている・冒頭に大きな日本語・静止ゼロ・末尾に1アクション。**

```
0–4秒    DAY9の夜（196秒付近）。敵5体に囲まれた画面から始める ← いちばん動く瞬間
4–9秒    元のプロンプト全文にズーム（13.5–15.5秒の素材）
9–13秒   DAY1の夜（22秒付近）。敵1体・装備1個
13–20秒  修正プロンプトにズーム（0–10秒の素材／共有カードは切る）
20–26秒  DAY9の夜に戻る。撃破49・装備7個
26–29秒  1アクション（体験会へ）
```

**狙い**：「少ない→多い」を時系列どおりに見せると単調になるので、**多い方を先頭に置いて掴み、
少ない方を対比として後から出す**。冒頭で「何が起きてるの？」を作れる。

### 尺の注意

生素材が203秒あるので、**30秒に収めるには切り捨てが大量に出る**。
ワークフローの「尺を伸ばしても見られない・平均再生時間は内容が違っても横並びになる」に従い、
DAY2〜DAY8はまるごと捨てる前提でよい。惜しければ**別の1本に割る**。

### 静止対策

**チャットのズーム区間は画面が止まる。** 21秒以降のチャットは変化量0.08で完全な静止。
ズーム中はゆっくりパンさせるか、ズームインの動き自体を見せる（Camtasiaのズーム＆パン）ことで
静止フレームを作らないこと。**書き出し後に必ず `freezedetect` で検算する。**

```bash
/usr/local/bin/ffmpeg -v info -i 書き出した.mp4 -vf "freezedetect=n=0.004:d=0.8" -map 0:v -f null - 2>&1 | grep -i freeze
```
