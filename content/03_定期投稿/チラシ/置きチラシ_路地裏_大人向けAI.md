# 置きチラシ｜路地裏GarageMarket・大人向けAI講座

- 用途: **会場に数枚置かせてもらう1枚**（ポスティングはしない）
- 印刷: 家庭用インクジェット・A4縦・普通紙で可
- 作成: 2026-09-02

---

## なぜこの形にしたか

**検索広告ではなくチラシにした理由。** 地域の検索データを見たところ、
大人が仕事のためにAIを探す検索は月20回弱しかなく、キーワード単価も
参加費に対して合わなかった（詳細は `~/curriculum/運営/決定ログ.md`）。

**「AIを仕事で使えたら」と思っている人はいるが、教室を探す語彙を持っていない。**
検索に出てこない相手には、こちらから言いに行くしかない。

**ポスティングはしない。** 冷たい一斉投函の反応率では数字が合わない。
置きチラシは相手がすでに会場まで来ている人なので、前提が違う。

### 狙いは2方向ある

| | |
|---|---|
| 来訪者に届く | 本来の目的 |
| **会場スタッフの方に届く** | **こちらが大きいかもしれない** |

2026-08-28に路地裏のスタッフの方から「盛り上がってましたね」と言われたが、
**大人向けAIをやっていることは認知されていなかった。**
紙が1枚あれば「大人向けもあるみたいですよ」と言ってもらえる可能性がある。
**会場の人が案内してくれるのは、こちらが配る何枚より効く。**

## ⚠️ 刷ってよい金額・刷ってはいけない金額

| | |
|---|---|
| **大人向け 2,900円 / レンタル 3,500円** | **刷ってよい。据え置きで10月の改定対象外** |
| 子ども向け 1,900円 / 900円 | **刷らない。10月から3,000円 / 2,000円に改定・未告知** |

紙は刷り直しが効かない。**子どもの金額を刷ると、10月以降そのチラシが嘘になる。**
子ども向けは「同じ日に開催している」とだけ書き、金額と日程はQRの先に任せる。

金額の正は [SCHEDULE-PATTERNS.md](../../04_共通/SCHEDULE-PATTERNS.md) の「参加費」。

> **詰め込まない。** 数枚しか置けないので、手に取る前に立ったまま読まれる。
> 遠目に何の紙か分かることを優先する。

  何から始めればいいか分からない方へ

## QRに入れるURL

```
https://hoshihirotaka.github.io/PlayMakerLabLP/adults.html?utm_source=flyer&utm_medium=print&utm_campaign=rojiura
```

**このパラメータを付けないと測れない。** いま帰属は申込フォームの自己申告しかないが、
これを付ければGA4で「チラシから来た人」が分離できる。
ブーストやDoorkeeper直行では取れていない精度になる。

## 印刷メモ

- A4縦・モノクロ可。普通紙で構わない
- **QRは2cm角以上**。インクジェットの普通紙は滲むので、小さくしない
- 刷るのは**数枚**。減っていたら補充する（減り方自体が反応の目安になる）

---

## 載せなかったものと、その理由

| 載せなかったもの | 理由 |
|---|---|
| 開催日 | 毎月変わる。刷り直しになるのでQRの先に任せる |
| 子ども向けの金額 | 10月に改定・未告知。紙に刷ると嘘になる |
| 実績の数字（3人に1人・9割など） | 立ったまま読む紙に入れると密度が上がりすぎる |
| 大人向けだけの単体訴求 | 「単体で押さない」方針（2026-08-30）。同じ日・同じ会場が武器 |

## 差し替えが必要になるとき

- **大人向けの参加費が変わったら**（いまは据え置きだが、いつかは動く）
- 会場が路地裏以外にも増えたら（「この場所です」が使えなくなる）
- **10月の値上げ告知の後**に、子ども向けの金額を載せる判断をしたら
