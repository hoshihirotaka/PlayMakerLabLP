## 決まったこと（2026-08-25）

### 10月からの正規の価格

| | いま（お試し価格） | 10月から | |
|---|---|---|---|
| Robloxコース | 1,900円 | **3,000円** | +1,100円 |
| AIコース（DreamCore・子ども向け） | 900円 | **2,000円** | +1,100円 |

**バナーでは以前どちらも3,000円と記載していた**が、AIは2,000円で確定。
**値上げと受け取られても致し方なし**、という判断（本人）。

大人向けAIコースはこの告知の対象外（すでに通常価格／アンケート回の2本立てで運用中）。

### 個別プラン（オンライン・自宅）の価格

**1時間 4,000円。Robloxか AIかを問わず一律**（本人の想定）。

会場でのグループ（通常プラン）とは別建て。1対1で見るぶん、時間あたりの単価が上がる。

> **「想定」の段階なので、告知では「予定しています」と書く。**
> 確定と書いて後から変えると、値上げそのものより信用を損なう。

### 開催頻度には触れない

当初「開催頻度が9月から減る」と告知する案だったが、**取り下げた。**

```
6月 1回 ／ 7月 3回 ／ 8月 2回 ／ 9月 3回 ／ 10月 2回（調整中）
```

- **9月は7月と同じ3回**で、減っていない
- **10月は増やすか検討中**（想定3回）。確定していないことを告知に書かない

**「この機会にどうぞ」の役割は、価格の話が担う。**
9月までがお試し価格の最後、という事実だけで十分に理由になる。
**存在しない希少性を作らない。**

### AIコースの時間延長には触れない

30分から延ばす検討はあるが、**この告知では書かない。**

- 各回のタイムテーブルはまだ30分のまま（8/28・9/19で確認）
- **値上げの理由として時間延長を持ち出さない。** 決まっていないことを
  引き合いに出すと、実施できなかったときに信用を損なう

延長が確定したら、**価格とは切り離して**別途お知らせする。

### コラボ投稿は承認しなかった（2026-09-06 判断）

投稿時に個人アカウントをコラボレータに招待したが、**承認せず公式単独のままにした。**

決定ログの「noteは個人アカウントで流す」で、読者と物差しを分けてある。

```
公式   南与野の保護者              申込につながるか
個人   ゲーム業界・CoderDojo関連    申込ではない
```

コラボにすると両方のフィードに載り、**この2つが1つの投稿の中で混ざる。**

**決め手は「この投稿は何で測るか」。**

| | |
|---|---|
| コラボの利点 | リーチが増える |
| ただし | **お知らせ投稿はリーチより反応の質を見る**（このファイルの方針） |
| コラボの代償 | **反応の出どころが混ざる** ＝ 唯一見たいものが濁る |

**得るものが小さく、失うものが的の真ん中**なので見送った。
9月は正常値を取る期間で「変更は1回に1つずつ」でもある。

**業界側に届ける価値自体は否定しない。** 個別プラン（オンライン）は地域を問わないので、
**個人アカウントから別途1本**出すほうが、物差しを分けたまま同じ層に届く（急ぎではない）。

#### なぜお知らせを先頭にしないか

**「スライドで始めると冒頭で大半が離脱する」**（[REEL-WORKFLOW.md](../../04_共通/REEL-WORKFLOW.md) の実証）。
