## 決まったこと（2026-08-25）

### 10月からの正規の価格

| | いま（お試し価格） | 10月から | |
|---|---|---|---|
| Robloxコース | 1,900円 | **3,000円** | +1,100円 |
| AIコース（DreamCore・子ども向け） | 900円 | **2,000円** | +1,100円 |

**バナーでは以前どちらも3,000円と記載していた**が、AIは2,000円で確定。
**値上げと受け取られても致し方なし**、という判断（本人）。

大人向けAIコースはこの告知の対象外（すでに通常価格／アンケート回の2本立てで運用中）。

### 個別プラン（オンライン・自宅）の価格

**1時間 4,000円。Robloxか AIかを問わず一律**（本人の想定）。

会場でのグループ（通常プラン）とは別建て。1対1で見るぶん、時間あたりの単価が上がる。

> **「想定」の段階なので、告知では「予定しています」と書く。**
> 確定と書いて後から変えると、値上げそのものより信用を損なう。

### 開催頻度には触れない

当初「開催頻度が9月から減る」と告知する案だったが、**取り下げた。**

```
6月 1回 ／ 7月 3回 ／ 8月 2回 ／ 9月 3回 ／ 10月 2回（調整中）
```

- **9月は7月と同じ3回**で、減っていない
- **10月は増やすか検討中**（想定3回）。確定していないことを告知に書かない

**「この機会にどうぞ」の役割は、価格の話が担う。**
9月までがお試し価格の最後、という事実だけで十分に理由になる。
**存在しない希少性を作らない。**

### AIコースの時間延長には触れない

30分から延ばす検討はあるが、**この告知では書かない。**

- 各回のタイムテーブルはまだ30分のまま（8/28・9/19で確認）
- **値上げの理由として時間延長を持ち出さない。** 決まっていないことを
  引き合いに出すと、実施できなかったときに信用を損なう

延長が確定したら、**価格とは切り離して**別途お知らせする。

## キャプション｜案B（レター調）★吟味中

箇条書きではなく、読み手に語りかける形。**本人の意向でこちらを軸に検討中。**

```
いつもありがとうございます。ブロマスゲームラボです。
ふたつ、お知らせがあります。

ひとつめは、参加費のことです。
これまで「今だけお試し価格」でご案内してきましたが、10月から正規の価格に戻させていただきます。

Robloxコース 1,900円 → 3,000円
AIコース 900円 → 2,000円

続けていくために必要な変更です。ご理解いただけますと助かります。9月の回までは、これまでの価格でご参加いただけます。

ふたつめは、新しいプランのことです。
「日程が合わなくて」という方が、これまでにもいらっしゃったかと思います。遠方の方も、送り迎えが難しい方もいらっしゃいました。

そういう方に向けて、オンラインとご自宅での個別対応をはじめます。遠方の方はオンラインで、近くにお住まいの方は気軽に立ち寄れる形で。1時間4,000円（Roblox・AIどちらも同じ）を予定しています。

会場に来られる方は、これまでどおりで大丈夫です。ご無理はなさらないでください。

しくみを整えて、順次ご案内していきます。
日程・お申し込みはプロフィールのリンクから。
```

### 案Bで意識したこと

| | |
|---|---|
| **語りかける** | 「ふたつ、お知らせがあります」で始め、読み手に話す形にした |
| **相手の事情を先に置く** | 値上げを言う前に「日程が合わなかった方」の話を出す。**新プランが誰のためかが先に伝わる** |
| **逃げ道を残す** | 「これまでどおりで大丈夫です／ご無理はなさらないでください」。**選択を迫らない** |
| **オンラインと自宅を書き分ける** | 遠方＝オンライン、近所＝自宅。**それぞれ別の人に向けた話**だと分かるように |

### 案Bの検討ポイント（吟味用）

- **「戻させていただきます」は硬いか。** 「戻します」のほうが素直かもしれない
- **金額を本文に入れるか、画像だけにするか。** キャプションが長くなるなら画像に寄せる手もある
- **「ふたつ、お知らせがあります」の言い方。** 「2点」より柔らかいが、好みが分かれる
- **末尾の締め。** いまは事務的なので、一言添える余地がある
