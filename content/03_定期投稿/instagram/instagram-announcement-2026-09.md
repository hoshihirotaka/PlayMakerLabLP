## ⚠️ 出す前に決めること（2点）

### ① 10月からの「正規の価格」はいくらか

記録に無い。いま出しているのは**お試し価格**。

| | いまの価格 | 正規の価格 |
|---|---|---|
| Robloxコース | 1,900円「今だけお試し価格」 | **未記録** |
| AIコース（子ども向け） | 900円「今だけお試し価格」 | **未記録** |
| 大人向けAIコース（PC持参） | 2,900円（アンケート回） | 3,900円 |
| 大人向けAIコース（レンタル付き） | 3,500円（アンケート回） | 4,200円 |

**金額を書くか書かないかで、下書きのA案／B案が変わる。** 下記参照。

### ② 「開催頻度が減る」のは9月からか10月からか

サイトの日程はこうなっている。**9月は7月と同じ3回**で、減るのは10月に見える。

```
6月 1回 ／ 7月 3回 ／ 8月 2回 ／ 9月 3回 ／ 10月 2回
```

「9月から減る」と書くと**サイトの日程と食い違う**。9月の回を実際に減らす予定なら合わせる。

### 1枚目｜表紙

```
運営からのお知らせ

ブロマスゲームラボ
2026年9月
```

### 2枚目｜価格

**A案（金額を書かない）**

```
10月から
正規の価格になります

これまで「今だけお試し価格」で
ご案内してきました。

決済のしくみが整うのに合わせて、
正規の価格に戻します。

続けていくために、
ご理解いただけますと助かります。
```

**B案（金額を書く）**

```
10月から
正規の価格になります

Robloxコース   1,900円 → ○,○○○円
AIコース         900円 → ○○○円

決済のしくみが整うのに合わせて、
正規の価格に戻します。

続けていくために、
ご理解いただけますと助かります。
```

> **B案のほうが親切。** 値上げの告知で金額を伏せると、かえって不安になりやすい。
> ただし金額が未確定なら A案 で出して、決まってから別途お知らせする形でもよい。

### 3枚目｜個別対応

```
オンラインと自宅での
個別対応をはじめます

会場に来られない方、
お子さんのペースに合わせたい方へ。

しくみを整えて、
順次ご案内していきます。
```

> ⚠️ **個別プランのページ（online-home.html）へのリンクは貼らないこと。**
> 限定公開のテスト中で `noindex` を維持している。
> 案内は公式LINE、または体験会当日にスタッフへお声がけいただく形のまま。

### 4枚目｜開催の回数

**A案（10月から・サイトの日程と一致）**

```
10月から
開催の回数を絞ります

1回ずつを、より丁寧に。

気になっている方は
9月の回にぜひどうぞ。
```

**B案（9月から・要件どおり）**

```
開催の回数を
絞っていきます

1回ずつを、より丁寧に。

気になっている方は
この機会にぜひどうぞ。
```

> B案は時期を書かないので、9月・10月どちらでも矛盾しない。**迷うならB案が安全。**

## 出したあとに見るもの

お知らせ投稿はリーチより**反応の質**を見る。

| 見るもの | なぜ |
|---|---|
| 保存 | 「あとで確認する」＝価格を気にしている人がいる |
| プロフィールアクセス | 日程を見に行ったか |
| DM・コメント | 値上げへの反応。**否定的な声が出たら早めに拾う** |

数値の記録は `~/curriculum/運営/リールインサイト/`（PRIVATE）へ。
