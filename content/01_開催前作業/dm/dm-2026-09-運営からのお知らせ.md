## ⚠️ 送る前に必ず直すもの

**公式LINEのあいさつメッセージに旧価格が入っている**（[公式LINE設定.md](../../04_共通/公式LINE設定.md) §2 フェーズ1・実装済み）。

```
・Robloxコース 1,900円
・AIコース 900円
```

**このまま送ると、「10月から3,000円」と読んだ直後に「1,900円」が自動送信される。**
[料金の棚卸し.md](../../04_共通/料金の棚卸し.md) の⑧がこれ。告知を出したあとに直す対象なので、
**DMの送信より先に直す。** あいさつメッセージは無料で何度でも変更できる。

## Instagramと書き方を変えているところ

| | Instagram | このDM |
|---|---|---|
| 公式LINE | 「**段階的に導入していく予定です**」 | 「**ご用意しました**」＋URL |

**矛盾ではない。宛先が違う。**

決定ログに「公式LINEは集客チャネルではない。**リピーターと個別プランのテスト用**。
新規の受け皿として使わない」とある。**DMの宛先＝過去にお越しいただいた方＝まさにその対象。**
Instagramは新規を含む不特定多数なので、言い切ると一斉登録に耐えられない。

両方を見る人がいるので、**「まだ一般には公開しておらず、みなさまに先にご案内しています」**を
入れてある。食い違いに見えず、先に案内された形になる。

### ⚠️ 「ご参加いただいた方」と書かない（2026-09-05 本人の指摘）

**Doorkeeperのグループには、登録だけで未参加の方が含まれる**
（[README](README.md) の募集DMの宛先「メンバー登録済み・**未参加など**」）。

当初「これまでお越しいただいた方から先に」と書いていたが、**未参加の方に
「自分宛てではない」と読まれる。** 参加の有無に触れず「まだ一般公開していない」
という事実だけで、先行案内であることは伝わる。

**値上げの告知は、むしろ検討中で未参加の方にこそ効く**（期限ができるため）。
本文の「迷われていた方は、この機会にぜひお越しください」がその人たち向け。

## 書いた理由・書かなかったこと

| | |
|---|---|
| 日程は `events/upcoming` の1リンク | 9月は3回あり、個別のイベントURLを3つ並べると選ばせる手間が増える。このURLは終了後も死なない |
| **UTMを付けていない** | 9月は付けない（評価開始日が2026-09-01。途中から見え方を変えない）。**10月のDMから付ける** |
| 「ご相談は無料／レッスンは4,000円」の1行 | 直前に「1時間4,000円」を出しているので、**無料相談と混同される**。境目を明示した |
| DreamCoreは最後に短く | 3つの中でいちばん影響範囲が狭い。ただし9/19が9月唯一の回なので、そこは書いた |
| 大人向けAIが対象外である旨 | 大人向けの参加者も同じグループにいる。「AIコース」だけだと自分の講座も上がると読まれる |
| **値引き・キャンペーンは書かない** | 料金改定を出す回で値引きの既得権を作らない（[dm/README](README.md) と同じ考え方） |

## 形式の注意（Doorkeeper）

- **行頭の `*` でリストを始めない。** 続く行が吸収されて1行につながる（2026-08-30に実際に崩れた）。
  `・` と普通の行で書いてある
- 見出し（`##`）は一斉配信のDMでも効く（2026-08-30・プレビューで確認済み）
- **送信前にプレビューで改行を確認する**
