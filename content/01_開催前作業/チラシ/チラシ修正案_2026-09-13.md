## 1. 「下部が目立たない」は、足すのではなく消すと直ります

定例の指摘はこれでした。

> 現在のチラシは**上部3分の2がAIで占められていて、下部が目立たない。**

**当日その場で配るなら、いま下部を埋めている情報のほとんどが要りません。**

| いま入っているもの | 当日配布では |
|---|---|
| 📍 場所・住所（〒338-0013 …） | **不要。** 受け取る人はもうそこにいます |
| 📝 お申し込み方法・QRコード | **不要。** その場で受け付けます |
| 「予約優先」 | **逆効果。** 「今からでは無理」と読まれます |
| 📩 お問い合わせ・メールアドレス | **不要。** 目の前に本人がいます |
| インスタのQR | **残す。** 今日来られない人の受け皿 |

**これだけで下3分の1が空きます。** レイアウトを組み直さなくても、
定例で言われた問題は消えます。

### 空いたところに置くもの

**受け取った人が知りたいのは1つだけです。「今からでも入れるのか」。**

```
今日、ここでやっています

  11:00  ゲームを作る（小1〜高校生）
  12:30  大人向けAI講座
  14:30  ゲームを作る（小1〜高校生）
  16:00  ゲームを作る（少し本格的に）

空きがあります。はじめてで大丈夫です。
スタッフに声をかけてください。
```

**「空きがあります」を必ず入れてください。** これが今日いちばん必要な一行です。

## 2. 2ページ目（子ども＋大人の併記）

定例では「**2つを1枚に併記するのが一番難しい**」という話でした。
**9/13に限れば、難しくありません。比率が偏っているからです。**

```
4コマ中3コマが子ども向けRoblox
残り1コマが大人向けAI
```

**面積もその比率にします。**

| 位置 | 中身 | 色 |
|---|---|---|
| **上 3分の2** | **子ども向けRoblox**（写真・作品・「ゲームを作る」） | **暖色（オレンジ・黄）** |
| **下 3分の1** | **大人向けAI講座を帯で1本** | **寒色（青）** |
| 最下部 | 今日の時間割＋「空きがあります」＋インスタQR | — |

**いまはAIが上3分の2を占めていて、逆になっています。**
定例で決めた色分け（AI＝寒色／Roblox＝暖色）は、**そのまま境目として使えます。**
**色が混ざっているのが問題だった**ので、上下で分けると混ざりようがありません。

### 大人向けの帯に入れる文（コピペ用）

```
【大人の方へ】12:30〜13:30
Google × AI 講座（60分・2,900円）

GmailとGoogleカレンダーを、AIとつなぎます。
コードは書きません。ご自身のPCで実際に動かします。
PCの貸出あり（3,500円・4台限定）
お子様の付き添いの時間に、どうぞ。
```

**最後の1行が効きます。** 子どもを①に出した保護者が、そのまま②に入れる時間割です。

## 3. 3ページ目（大人向け単体）に足すもの

「もう少し詳しく」というのは、**何をやるかが書いていない**ということだと思います。
Doorkeeperの原稿にもう書いてあるので、そこから3行だけ持ってきます。

```
今回やること（60分・全部ご自身のPCで動かします）

・Geminiから自分のGoogleカレンダーに予定を入れる
　「明日14時に〇〇の予定を入れて」で入ります

・Gmailを読ませて、要点だけ受け取る
　「先月のうち、私に関係ありそうな話だけ拾って」

・AIの間違いとの付き合い方／入れてよい情報・避けたい情報

コードは書きません。
ゴールは「全部できる」ことではなく、帰ってから自分で再現できることです。
```

### こんな方におすすめ（4行に絞る）

```
・GmailやGoogleカレンダーは毎日使うが、AIとつないだことはない
・「便利そう」とは思うが、設定で止まっている
・メールが溜まって、大事なものが埋もれている気がする
・AIを「検索の代わり」としてしか使えていない
```
