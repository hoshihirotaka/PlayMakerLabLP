## 1. ⚠️ まず直すべき誤解（2ページ目）

### 子ども向けの時間が「通し」で書かれています

```
9/13（日）11:00-17:00
9/19（土）13:00-19:20
9/25（金）16:50-19:20
```

**これは6時間の教室に見えます。** 実際は**1時間のコマが3つ**です。

**直し方（9/13ぶん）**

```
9/13（日）11:00 / 14:30 / 16:00　各1時間
　※ 11:00 と 14:30 は同じ内容です。はじめての方はどちらでも
　※ 16:00 は少し本格的に作りたい方向け
```

**「受けたい回だけ」が伝わらないと、6時間拘束だと思われて終わります。**

### 「予約優先」は当日配布では逆効果です

**「もう遅い」と読まれます。** 明日必要なのは反対の一行です。

```
空きがあります。その場でご参加いただけます。
```

### 「同日開催：」というラベル

**子ども向けを「ついで」に見せています。**
明日の会場にいるのは日曜の市場に来た家族連れで、**コマも4つ中3つが子ども向け**です。
**主役が逆になっています。**

## 2. 2ページ目の組み替え

定例で「**2つを1枚に併記するのが一番難しい**」という話でしたが、
**9/13に限れば比率が決まっているので迷いません。**

| 位置 | 中身 | 色 |
|---|---|---|
| **上 3分の2** | **子ども向けRoblox**（お題・作品・「今日やっています」） | **暖色（オレンジ・黄）** |
| **下 3分の1** | **大人向けAI講座を帯で1本** | **寒色（青）** |
| 最下部 | 今日の時間割ぜんぶ ＋ インスタQR | — |

**定例で決めた色分け（AI＝寒色／Roblox＝暖色）が、そのまま上下の境目に使えます。**
**「色が混ざっているのが問題」だったので、面で分ければ混ざりません。**

### 上に置く文（コピペ用）

```
今日、ここでゲームを作っています

今月のお題「キーボードの上を走るコース」
　・キーボードのアセットを並べる
　・スピードアップのスクリプトを入れる

小1〜高校生／パソコンは会場にあります／はじめてで大丈夫
1,900円（今だけのお試し価格）
```

**「今月のお題」はいまも入っていて、これは強いです。** 具体的で、子どもが分かります。
**下から上に移してください。**

### 下の帯に置く文（コピペ用）

```
【大人の方へ】今日 12:30〜13:30
Google × AI 講座（60分・2,900円／PC貸出あり 3,500円）

GmailとGoogleカレンダーを、AIとつなぎます。
コードは書きません。ご自身のPCで実際に動かします。
お子様が①に出ている時間に、どうぞ。
```

**最後の1行が効きます。** 11:00に子どもを出した保護者が、そのまま12:30に入れる時間割です。

## 3. 3ページ目（大人向け単体）

### 「もう少し詳しく」の正体は、**何をやるかが1行も無いこと**です

いま載っているのは「こんな方におすすめ」3行と、参加条件と、価格と、定員だけです。
**講座の中身が書いてありません。**

**足す文（コピペ用・Doorkeeper原稿から）**

```
今回やること（60分・全部ご自身のPCで動かします）

・Geminiから自分のGoogleカレンダーに予定を入れる
　「明日14時に〇〇の予定を入れて」で入ります

・Gmailを読ませて、要点だけ受け取る
　「先月のうち、私に関係ありそうな話だけ拾って」

・AIの間違いとの付き合い方／入れてよい情報・避けたい情報

コードは書きません。
ゴールは「全部できる」ことではなく、帰ってから自分で再現できることです。
```

### 2種類の回があるのに、違いが書いてありません

```
🕒 カレンダー・メールをAIに任せる回　9/13・9/19
🕒 資料からスライドを作る回　　　　　9/19・9/25
```

**題だけで、中身が無いので選べません。** 片方（今日の回）だけ上の3行を足せば足ります。
**もう片方は1行で十分です。**

```
※「資料からスライドを作る回」は、手元の資料をAIに読ませて、
　 どこに書いてあったかまで示させる回です（9/19夜・9/25夜）
```

### 当日配るなら、今日の回を主役に

**4つの日程が同じ大きさで並んでいます。** 明日渡す紙なら、

```
今日 12:30〜13:30 ← 大きく
ほかの回もあります（9/19・9/25）← 小さく
```
