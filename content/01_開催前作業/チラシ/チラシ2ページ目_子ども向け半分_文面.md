## 体験会でやること（上半分の「今回やること」と同じ位置）

```
体験会でやること（1時間・パソコンは会場にあります）

・キーボードのアセットを並べて、コースを作る
・スピードアップのスクリプトを入れる
・最後に、その場でみんなに遊んでもらう

はじめてで大丈夫です。パソコンの操作から教えます。
何を作るか決めていなくても問題ありません。
```

> **3つ目が効きます。** 作って終わりではなく、**その場で感想がもらえる**のがこの教室の形です。
> 発表会を待たない、というのはサイトにも書いてある柱です。

## ⚠️ 日程（枠で囲う・毎月ここだけ差し替え）

```
📅 今月の日程

9/13（日）11:00 / 14:30 / 16:00　各1時間
9/19（土）13:00〜19:20 のうち各1時間
9/25（金）16:50〜19:20 のうち各1時間
```

**⚠️ 通しの時間だけを書かないこと。**
いまのページには `9/13（日）11:00-17:00` と書いてあり、**6時間の教室に見えます。**
実際は1時間のコマが3つです。**「受けたい回だけ」が伝わらないと、拘束時間だと思われます。**

**9/13の補足（入れる余裕があれば小さく）**

```
※ 11:00 と 14:30 は同じ内容です。はじめての方はどちらでも
※ 16:00 は、少し本格的に作りたい方向け
```
