# チラシの色（2026-09-12 確定）

定例（2026-09-08）で決めたこと。

> **AI向け＝寒色（青系）／Roblox向け＝暖色（オレンジ・黄）で、はっきり色を分ける。**
> いまは色が混ざっているのが問題。Robloxは以前から紫系も使っていて、そこも重なっている。

**サイト（`style.css`）と同じ値を使います。** 紙と画面で見た目が揃います。

---

## 大人向けAI（寒色）← 3ページ目

| 用途 | 色 | 由来 |
|---|---|---|
| **帯・見出しの地・バッジ・矢印** | **`#0F2C59`**（濃紺） | サイトの見出し色 |
| **背景・本文の下地** | **`#EAF2FB`**（淡い青） | `--bg-2` #f0f6ff をわずかに濃く |
| 帯の上の文字 | `#FFFFFF` | |
| 本文の文字 | `#1A2333` | `--text` |
| 補助の文字 | `#495972` | `--subtext` |
| 強調したいとき | `#3CC2FF`（明るい青） | `--accent-2` |

**2026-09-12に3ページ目へ適用済み。**

## 子ども向けRoblox（暖色）← 2ページ目の上部

| 用途 | 色 | 由来 |
|---|---|---|
| **帯・見出しの地** | **`#FF6B6B`**（コーラル） | `--accent` |
| **差し色・お題まわり** | **`#FFD166`**（黄） | `--accent-3` |
| 背景・本文の下地 | `#FFF8EF`（淡いクリーム） | `--bg` #f7f5f0 を暖かく |
| 本文の文字 | `#1A2333` | |

## 2ページ目（併記）の使い分け

```
上 3分の2   子ども向けRoblox   #FF6B6B ＋ #FFD166   地は #FFF8EF
下 3分の1   大人向けAIの帯      #0F2C59              文字は白
```

**上下で面を分ければ、色が混ざりません。** これが定例で言われた「混ざっているのが問題」への答え。

---

## ⚠️ 紫は使わない

Robloxで以前から紫系を使っていて、**AI側の青と重なります。**
**紫はどちらにも寄るので、2つを分ける目的では使わない。**

## ⚠️ 印刷のこと

**自分で10枚刷る前提です**（定例）。

- **地をベタで濃く塗らない。** インクを食い、家庭用プリンタでは筋が出ます
- **3ページ目は淡い青の地に濃紺の帯**にしてあるので、その点は大丈夫です
- 紺は印刷でやや沈みます。**薄く出たら `#14386F` くらいまで上げる**

## Canvaでの変え方

1. 変えたい要素をクリック
2. 上のツールバーの**色の丸**をクリック
3. 検索欄に**`#0F2C59` のようにHEXを打つ**
4. 出てきた色をクリック
5. 下に出る**「すべて変更」→「現在のページ」**で、同じ色の要素をまとめて置換

⚠️ **「すべてのページ」は押さないこと。** 15ページ全部が変わり、
**子ども向けの暖色まで青になります。**
