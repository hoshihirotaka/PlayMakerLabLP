## なぜ「日程が出そろいました」で始めるか

**9/13は単独ですでに投稿済み。** そのまま3日程版を出すと重複に見える。

冒頭を「日程が出そろいました」にすると、**同じ内容の再投稿ではなく、
情報が揃ったことの報告**になる。予定を早く決められるようになった、という
運営側の変化がそのまま理由になっている。**謝る必要はない。**

## 書いた理由・書かなかったこと

| | |
|---|---|
| 時間は子どもの回の終わりまで | 9/19・9/25の「20:30」は大人向けの終了時刻。子ども向けに書くと遅く見える |
| 「3回とも同じお題」を明記 | 3日程を並べると「同じ内容を3回？」と読まれる。DMにも書いた内容 |
| **9/19のAIコース900円を注記** | 9/19だけ③AIコース（DreamCore・900円）がある。1,900円だけだと不正確 |
| プログラミングありの回の中身は書かない | 教材が作成中。差し替えたときに嘘になる |
| 大人向けは2行だけ | 読者層が違う。別投稿で扱う |

### ⚠️ 自分で付けた呼び名をタグにしない（2026-09-02）

当初 `#キーボードラン` を入れていたが、**これは教材につけたこちらの呼び名**で、
検索している人がいない。**5枠のうち1つを、誰も使わない語に充てていた。**

タグで地域の小規模教室が発見される確率は低く、実際は
**「この投稿が何の話か」をアルゴリズムに伝える分類ラベル**として働く。
だとすれば、**人が実際に使っている語でないと機能しない。**

`#プログラミング教室` に差し替えた（2026-09-02 本人判断）。

### 元ゲームのタイトルはタグに使わない（2026-09-02 本人判断）

教材の元になっているRobloxのゲームには別のタイトルがある。
そのタグを使えば「そのゲームを知っている層」に届くが、
**他社タイトルに乗る形になるので使わない。**

**`#土日開催` も検索母数は小さい**が、情報としては正しいので残している。
