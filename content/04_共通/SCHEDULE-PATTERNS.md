# タイムスケジュールのパターン集

会場・曜日ごとの**コマ割りの型**をここにまとめる。

これまでは `events/YYYY-MM-DD.js` や Doorkeeper下書き・DM・Instagram原稿にそれぞれ時刻を書いていたため、
回ごとの差分がどこにあるのか分かりにくく、食い違い（設営の抜け・延長タイムの表記ゆれ）が実際に起きていた。
**パターンをここに独立させ、各回はここから当てはめる**。ズレが出たらこのファイルとすり合わせる。

- 各回の正本は引き続き `events/YYYY-MM-DD.js`。このファイルは「型」であって個別回の値ではない
- 型を変えたときは、このファイルを直してから各原稿に展開する

## 1. 組み立ての単位（ブロック）

### 大原則

> **授業60分 ＋ 入れ替え10分＝70分がすべての基本。**
> **Robloxの体験だけ、そこにプレイ会20分が加わって90分になる。**
> （プレイ会の20分は、表では「延長タイム・親御様個別相談」と書く → §5）

パターンはすべて、この基本から派生した次の5種類のブロックの並びで表せる。
**時間の長さはブロック側で固定**、変わるのは開始時刻と並べ方だけ。

| ブロック | 構成 | 占有 | 何のコマか |
|---|---|---|---|
| **体験ブロック** | Robloxコース60分 ＋ **延長タイム・親御様個別相談**20分 ＋ 設営・入れ替え10分 | **90分** | 初めての人向け。アスレチック／宝探し／アバターから選ぶ |
| **AIブロック** | AIコース30分 ＋ 休憩20分 | **50分** | DreamCore |
| **カリキュラムブロック** | Robloxコース60分 ＋ 設営・入れ替え10分 | **70分** | プログラミングあり。特定教材で継続する回 |
| **個別プランブロック** | 個別プラン60分 | **60分** | 事前に参加者から希望者を募る |
| **大人向けブロック** | 設営・入れ替え10分 ＋ 大人向けAIコース60分 | **70分** | 保護者様向けの**別イベント**（Doorkeeper別枠） |

10分の切れ目は**設営・入れ替え**、AIブロックの20分だけ**休憩**と書く（実際に休む時間のため）。

### 参加費（2026-08-12 時点）

| コマ | 参加費 | `price` フィールド |
|---|---|---|
| Robloxコース（体験・カリキュラムとも） | **1,900円** | 使う → 「今だけお試し価格」バッジが付く |
| AIコース（DreamCore・子ども向け） | **900円** | 使う → 同上 |
| 大人向けAIコース | **未確定** | **使わない**。label内に金額を書く |
| 個別プラン | 別途ご案内 | 使わない |

- 「今だけお試し価格」は値上げ時期が未定のまま出している表記。**勝手に外さない**
- 大人向けの8/28実績は2,900円／PCレンタル付き3,200円だが、これは
  「アンケートにご協力いただく回だから」の1,000円引き。**通常は3,900円**。9月分は未確定
- 大人向けに `price` を使わないのは、値引き理由が子ども向けと別建てでバッジが付くと誤解を招くため

### ブロックの使い分け（重要）

- **20分の延長タイムが付くコマが「体験」**。中身は他の人が作ったゲームで遊び合う時間で、
  参加者が「一番楽しかった」に挙げるのはここ（[HANDOFF](../HANDOFF-2026-08-11.md) §8）。体験コマから外さない
- **「プログラミングあり」のコマは継続カリキュラム**。延長タイムは付けない。
  **体験会で基礎を覚えた方向け**のコマなので、告知にはそう書く（→ §7 の定型文）。
  **2026年10月から特定教材で募集する**（アスレチック or Prop Hunt。教材は確定したらここに書く）

### 準備・撤収（参加者向けに出さない）

| | |
|---|---|
| 準備 | 開始の**1時間前**から（例: 11:00開始なら10:00〜） |
| 撤収 | 終了の**1時間後**まで（例: 17:00終了なら〜18:00） |

会場の押さえは「公開している開始〜終了の前後1時間ずつ」で見積もる。

**「設営・入れ替え」は媒体で扱いが違う。**

| 媒体 | 扱い |
|---|---|
| Doorkeeper・LP（events/*.js）の表 | **載せる**（8/28の公開ページも載せている） |
| 当日資料「当日：ブロマス」（Canva） | **載せない**（AGENTS.md「当日資料」の方針） |

**標準形との差**は「子ども向けAI30分 → 大人向けAI60分」と「カリキュラム枠と個別枠を1つに束ねた」の2点だけ。
**体験2枠は標準形のまま残る**ので、新規の受け入れ数は落ちない。

**この形の良いところ**

- **大人向けAIを金曜夜以外にも出せる**。日曜の日中しか動けない保護者を拾える
- ①に子どもが入っている間、保護者は待ち時間になっている。**その保護者がそのまま②を受けられる**導線になる
- 講師が通しで回すときの**まとまった休憩が初めて確保**できる（8/9は5コマ通しで昼休憩なしだった）
- ④を束ねたことで、**継続生が少ない回はカリキュラム、多い回は個別**と回ごとに寄せられる

### ④の書き方（同一枠に2つ載せる）

`timetable` は同じ `time` の行を並べられるので、**2行に分けて書く**。1行にまとめるより、
**料金が別々に出せる**（個別プランには `price` を付けない）ぶん分かりやすい。

```js
    { time: "16:00-17:00", label: "④個別プラン" },
    { time: "16:00-17:00", label: "④Robloxコース（プログラミングあり）", price: "1,900円" }
```

`note` に一文添える。

> ※④は個別プランとRobloxコース（プログラミングあり）のどちらかを実施します。
> 事前にご希望をうかがったうえで決定し、申込者の皆さまにご連絡します。

**決める前に確認したいこと**

- [ ] **④は「選択制」でよいか。** 講師1人なので**同時開催はできない**前提で書いてある。
      両方を同時に走らせたい場合は、④を2コマに割る（＝17:00終了を動かす）必要がある
- [ ] **④をどちらにするか決める締切。** 申込者への連絡が要るので、開催の何日前までに確定するかを決める
- [x] ~~②の間、子どもはどうするか~~ → **2026-08-12 解決。同席OK・空いたPCで続きを進めてもOK**。
      待機時間がそのまま制作時間になる。告知の定型文は §7 に置いた
- [ ] **子ども向けAIコース（DreamCore・900円）が日曜から消える。** 標準の金曜パターンにもAIはないので、
      **どの回でも子ども向けAIを提供しない**ことになる。意図どおりか
- [ ] **12:30〜13:30は昼食の時間帯。** 大人向けの集まりが悪いなら13:00〜14:00にずらす（休憩を前後で分ける）
- [ ] **土曜の案B（§4）は「日曜パターンそのまま＋夜の部」**。日曜をこの派生案にするなら土曜も連動して変わる

## 7. `events/*.js` への落とし方

パターンを決めたら timetable に展開する。詳しい書式は [AGENTS.md](../../AGENTS.md) の「イベント管理の仕様」。

```js
  timetable: [
    { time: "11:00-12:00", label: "①Robloxコース", price: "1,900円" },
    { time: "12:00-12:20", label: "延長タイム・親御様個別相談" },
    { time: "12:20-12:30", label: "設営・入れ替え" },
    { time: "12:30-13:00", label: "②AIコース", price: "900円" },
    // ...
    // 大人向けは price を使わず label 内に金額を書く（バッジを付けないため）
    { time: "19:30-20:30", label: "③大人向けAIコース（仕事活用初心者向け）　2,900円 / PCレンタル付き 3,200円" }
  ]
```

- `price` を入れると「今だけお試し価格」バッジが自動で付く。**大人向けには付けない**（値引き理由が別建て）
- 大人向けは Doorkeeper が別イベント。`note` に申込リンクを書く（**回ごとにURLが変わる。前回のURLを流用しない**）

### `note` の定型文

タイムテーブルの直下に出る。該当するものを組み合わせて使う。

**大人向けAIコースがある回**

> ③大人向けAIコースは保護者様ご自身向けの**別イベント**です（お申し込みは別枠）。
> **③の時間帯は、お子様にも同席いただけます。**空いているパソコンを使って、
> ご自身の続きを進めていただいても問題ありません。

保護者だけが受講して子どもが手持ち無沙汰になる、という不安を先に消す一文。
子どもの待機時間がそのまま制作時間になる。

**夜の回（金曜パターン）では終了時刻を足す。**

> （**20:30には終了します**。延長はありません）

金曜は大人向けが最終コマなので、**その前のコマを受けた子は保護者の送迎待ちで会場に残ることが確定する**。
「認めるかどうか」ではなく最初からそうなる状態なので、書かないと
「その1時間、子どもはどうすれば？」という不安で大人向けの申込が落ちる。
**日曜より金曜のほうがこの一文は必要。** 遅い時刻への不安は、終了時刻を明示して打ち消す。

**Robloxコース（プログラミングあり）がある回**

> Robloxコース（プログラミングあり）は、**体験会で基礎を覚えた方におすすめ**の回です。

初めての人が誤って申し込むのを防ぎつつ、体験会からの**次の一歩**として見せる。

**個別プランとカリキュラムを同一枠にした回**

> ④は**個別プランとRobloxコース（プログラミングあり）のどちらかを実施**します。
> 事前にご希望をうかがったうえで決定し、申込者の皆さまにご連絡します。

**参加費・Doorkeeperが未確定の回（comingSoon）**

> 時間が決まりました。参加費・お申し込み方法は準備でき次第このページでお知らせします。
