# タイムスケジュールのパターン集

会場・曜日ごとの**コマ割りの型**をここにまとめる。

これまでは `events/YYYY-MM-DD.js` や Doorkeeper下書き・DM・Instagram原稿にそれぞれ時刻を書いていたため、
回ごとの差分がどこにあるのか分かりにくく、食い違い（設営の抜け・延長タイムの表記ゆれ）が実際に起きていた。
**パターンをここに独立させ、各回はここから当てはめる**。ズレが出たらこのファイルとすり合わせる。

- 各回の正本は引き続き `events/YYYY-MM-DD.js`。このファイルは「型」であって個別回の値ではない
- 型を変えたときは、このファイルを直してから各原稿に展開する

---

## 1. 組み立ての単位（ブロック）

### 大原則

> **授業60分 ＋ 入れ替え10分＝70分がすべての基本。**
> **Robloxの体験だけ、そこにプレイ会20分が加わって90分になる。**
> （プレイ会の20分は、表では「延長タイム・親御様個別相談」と書く → §5）

パターンはすべて、この基本から派生した次の5種類のブロックの並びで表せる。
**時間の長さはブロック側で固定**、変わるのは開始時刻と並べ方だけ。

| ブロック | 構成 | 占有 | 何のコマか |
|---|---|---|---|
| **体験ブロック** | Robloxコース60分 ＋ **延長タイム・親御様個別相談**20分 ＋ 設営・入れ替え10分 | **90分** | 初めての人向け。アスレチック／宝探し／アバターから選ぶ |
| **AIブロック** | AIコース30分 ＋ 休憩20分 | **50分** | DreamCore |
| **カリキュラムブロック** | Robloxコース60分 ＋ 設営・入れ替え10分 | **70分** | プログラミングあり。特定教材で継続する回 |
| **個別プランブロック** | 個別プラン60分 | **60分** | 事前に参加者から希望者を募る |
| **大人向けブロック** | 設営・入れ替え10分 ＋ 大人向けAIコース60分 | **70分** | 保護者様向けの**別イベント**（Doorkeeper別枠） |

10分の切れ目は**設営・入れ替え**、AIブロックの20分だけ**休憩**と書く（実際に休む時間のため）。

### ブロックの使い分け（重要）

- **20分の延長タイムが付くコマが「体験」**。中身は他の人が作ったゲームで遊び合う時間で、
  参加者が「一番楽しかった」に挙げるのはここ（[HANDOFF](../HANDOFF-2026-08-11.md) §8）。体験コマから外さない
- **「プログラミングあり」のコマは継続カリキュラム**。延長タイムは付けない。
  **2026年10月から特定教材で募集する**（アスレチック or Prop Hunt。教材は確定したらここに書く）

### 準備・撤収（参加者向けに出さない）

| | |
|---|---|
| 準備 | 開始の**1時間前**から（例: 11:00開始なら10:00〜） |
| 撤収 | 終了の**1時間後**まで（例: 17:00終了なら〜18:00） |

会場の押さえは「公開している開始〜終了の前後1時間ずつ」で見積もる。

**「設営・入れ替え」は媒体で扱いが違う。**

| 媒体 | 扱い |
|---|---|
| Doorkeeper・LP（events/*.js）の表 | **載せる**（8/28の公開ページも載せている） |
| 当日資料「当日：ブロマス」（Canva） | **載せない**（AGENTS.md「当日資料」の方針） |

## 4. 土曜・路地裏GarageMarket（**検討中**）

**会場は 11:00〜20:30 まで押さえられる ＝ 570分。6時間を超える枠を組める初めてのパターン。**

これまでは「日曜＝日中（360分）」「金曜＝夜（230分）」と、**どちらか片方しか入らなかった**。
土曜は両方入る。子どもも保護者も一日空いている唯一の曜日でもある。

### 先に固定できる2点

| | |
|---|---|
| **終わり** | 大人向けAIコース **19:30〜20:30**。金曜と同じ位置。会場の終わりが20:30なのでここは動かせない |
| **子どもの部の持ち時間** | 11:00〜19:20（大人向けの設営10分を引く）＝ **500分** |

**500分をどう使うかが、このパターンの設計そのもの。** 以下3案。

---

### 案A｜最大枠型（8コマ）

`体験90 → AI50 → 体験90 → カリキュラム70 → 体験90 → AI50 → 個別60 → 大人向け70` ＝ 570分（ぴったり）

- 体験3枠・AI2枠・カリキュラム1枠・個別1枠・大人向け1枠
- **枠は最大**。1日で最も多く集められる
- 通しで9時間半、講師の休憩は各ブロック内の10〜20分のみ。**現実的に回せるかは要検討**

---

### 案B｜二部制（日曜型 ＋ 夜の部）★おすすめ

`【日中の部】日曜パターンそのまま 11:00〜17:00` ＋ `【中休み50分】` ＋ `【夜の部】体験90 → 大人向け70`

| 内容 | 時間 | 備考 |
|---|---|---|
| ①〜⑤ | 11:00〜17:00 | **§2 の日曜パターンをそのまま使う** |
| 中休み | 17:00〜17:50 | 講師の食事・リセット。非公開 |
| ⑥Roblox | 17:50〜18:50 | アスレチック／宝探し／アバター |
| 延長タイム・親御様個別相談 | 18:50〜19:10 | |
| 設営・入れ替え | 19:10〜19:20 | |
| ⑦大人向けAIコース | 19:30〜20:30 | 保護者様向け・**別イベント**。申込は別リンク |

**なぜこれを推すか**

- 日中は**5回運用して固まっている型をそのまま流用**できる。新しく設計するのは夜の部だけで、運用リスクが最小
- ⑥は夕方の体験枠。**金曜の夜に来られない層**（習い事・部活と重なる子）を拾える
- 中休み50分が入るので、通しでも回せる見込みが立つ
- 「日曜型＋金曜型」という説明が保護者にもそのまま通じる

---

### 案C｜カリキュラム2連型（10月以降向け）

`体験90 → AI50 → カリキュラム70 → カリキュラム70 → 体験90 → 個別60 → 中休み70 → 大人向け70` ＝ 570分

- 10月から特定教材で継続募集を始めるので、**同じ子が1日で2コマ分進められる**形
- 継続の受け皿としては強いが、**継続生が集まってから**でないと空振りする
- 10月以降の選択肢として置いておく

---

### 決めること

1. **500分に何を入れるか**（案A / B / C）— 枠の最大化か、回せる形か、継続の受け皿か
2. **大人向けAIコースを土曜にも置くか** — 金曜夜と食い合わないか。土曜のほうが保護者は来やすいはず
3. **11:00〜20:30に準備・撤収が含まれるか** — 含むなら公開できる帯は12:00〜19:30に縮む（→ §8）

決まったら1案を残し、このセクションを「確定パターン」に書き換える。

## 5. 表記（2026-08-12 確定）

**「延長タイム・親御様個別相談」「設営・入れ替え」で統一する。「プレイタイム」は使わない。**

| 実体 | 表記 |
|---|---|
| 体験コマ後の20分 | **延長タイム・親御様個別相談** |
| コマ間の10分 | **設営・入れ替え** |
| AIコース後の20分 | **休憩** |

### 経緯（同じ検討を繰り返さないために）

一度「プレイタイム」への変更を検討したが、**現行表記のまま**とした。調べた結果は以下。

- Doorkeeper 8/28（最新の公開ページ・events/198459）は「延長タイム・親御様個別相談」「設営・入れ替え」。
  **「プレイタイム」は表にも本文にも一度も出てこない**
- リポジトリ内も同じ。`events/*.js`・Doorkeeper下書き・DM原稿すべてが現行表記で揃っている
- つまり「プレイタイム」への変更は*戻す*のではなく*新しく変える*話で、直す先が6か所以上あった

DM・Doorkeeperの定型文もこのままでよい。

> ※各セッションの後には「延長タイム・親御様個別相談」の時間も設けています。
> お子様の続きの作業や、通い方のご相談などにご活用ください。

**中身が「他の人のゲームで遊び合う時間」であることは、表の名前ではなく本文で伝える**
（[HANDOFF](../HANDOFF-2026-08-11.md) §8 の発見をInstagram等の告知本文で使う）。

## 6. テンプレート化しない会場

### 浦和（レンタルスペース）

- 開催実績1回（2026-07-18）のみ
- **レンタルスペースのため取れる時間帯が回ごとにバラバラ**で、固定の型を置けない
- 押さえられた枠に対して §1 のブロックを詰める形で毎回組む

この「ブロック単位で組み直す」やり方が、**他エリアに展開するときの基本形**になる。
新しい会場では、まず押さえられる時間の長さを測り、ブロックを並べて何コマ入るかを出す。

| 押さえられる時間 | 入る構成 |
|---|---|
| 3時間 | 体験(90) → カリキュラム(70) ＝160分 |
| 4時間 | 体験(90) → カリキュラム(70) → 大人向け(70) ＝230分（金曜型） |
| 6時間 | 日曜型（体験・AI・体験・カリキュラム・個別） |
| 7時間 | 土曜型（日曜型＋大人向け） |

## 7. `events/*.js` への落とし方

パターンを決めたら timetable に展開する。詳しい書式は [AGENTS.md](../../AGENTS.md) の「イベント管理の仕様」。

```js
  timetable: [
    { time: "11:00-12:00", label: "①Robloxコース", price: "1,900円" },
    { time: "12:00-12:20", label: "延長タイム・親御様個別相談" },
    { time: "12:20-12:30", label: "設営・入れ替え" },
    { time: "12:30-13:00", label: "②AIコース", price: "900円" },
    // ...
    // 大人向けは price を使わず label 内に金額を書く（バッジを付けないため）
    { time: "19:30-20:30", label: "③大人向けAIコース（仕事活用初心者向け）　2,900円 / PCレンタル付き 3,200円" }
  ]
```

- `price` を入れると「今だけお試し価格」バッジが自動で付く。**大人向けには付けない**（値引き理由が別建て）
- 大人向けは Doorkeeper が別イベント。`note` に申込リンクを書く（**回ごとにURLが変わる。前回のURLを流用しない**）
