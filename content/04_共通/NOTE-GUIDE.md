# ブロマスゲームラボ note 制作ガイド

noteはファネル上「信頼構築・取り組みの深さ」を担うチャネル。  
インスタが雰囲気訴求なのに対し、noteは「なぜやっているか」「現場で何が起きているか」を伝える場。

> 書いた原稿をnoteの編集画面へ流し込む手順は [NOTE-EDITOR-AUTOMATION.md](NOTE-EDITOR-AUTOMATION.md) を参照。

---

## ファイル命名規則

```
note-session-XX.md          # 活動報告（回数）
note-monthly-YYYY-MM.md     # 月次振り返り（月に1本）
note-column-XX-slug.md      # 技術・考察コラム（連番＋内容を示すslug）
note-YYYY-MM-DD.md          # 回数に紐づかない単発記事
```

### コラム記事のslug例
```
note-column-01-markdown-materials.md   # 教材マークダウン化の話
note-column-02-ai-workflow.md          # AIワークフローの詳細
note-column-03-game-design-thinking.md # ゲームデザイン思考について
```

---

## 記事の種類と使い分け

| 種類 | 頻度 | 内容 | ファイル形式 |
|------|------|------|------------|
| 活動報告 | 毎回開催後 | 当日の様子・反省・気づき | `note-session-XX.md` |
| 月次振り返り | 月に1本 | 開催日以外の27日間にやっていたこと（仕組み・判断・試行錯誤） | `note-monthly-YYYY-MM.md` |
| 技術・考察コラム | 不定期 | AI活用・教材づくり・ゲームデザイン思考など | `note-column-XX-slug.md` |
| お知らせ | イベント前後 | 開催情報・募集（インスタの補足として） | `note-YYYY-MM-DD.md` |

**活動報告と月次振り返りは役割が違う。** 活動報告は「当日の教室で何が起きたか」、
月次振り返りは「その裏で何を作っていたか」。内容は重ならせない。

## 活動報告のテンプレート

```markdown
# ブロマス活動報告 第XX回（さいたま市｜南与野・与野本町）

XX回目の開催にあたっての活動報告をさせていただきます。

## （番外編・補足があれば）

前回からの出来事や、本題に入る前のトピックがあれば記載。

---

## 第XX回 Robloxコース

- 参加者の傾向（新規／リピート、レベル感）
- 体験した内容・個別対応のエピソード
- うまくいったこと・反省点

## 第XX回 AIコース

- 参加者の傾向
- 印象に残った場面・気づき
- 親御さんとのやり取りがあれば

---

## 次回について

次回は**X月X日（X）HH:MM〜HH:MM**です。（開催形式や試みがあれば一言）

引き続き、よろしくお願いします。

---

#ブロマスゲームラボ #Roblox #AI #ゲーム制作 #子ども向けプログラミング #プログラミング教室 #ゲームクリエイター #さいたま #南与野 #与野本町 #ワークショップ #活動報告
```

## 月次振り返りのテンプレート

構成・テーマの選び方・除外する情報・公開前チェックは、専用の雛形にまとめてある。

→ [content/02_開催後作業/note/note-monthly-template.md](../02_開催後作業/note/note-monthly-template.md)

元ネタは月次振り返りマークダウン（`{英語月名}_2026_review.md`）、
または期間区切りの日報まとめ（`chat_summary_*.md`）。
毎月1日にスケジュールタスク `monthly-note-draft` が前月分の初稿を自動生成する。

タグは末尾に以下を使う（`#活動報告` の代わりに `#教室運営 #月次振り返り`）：

```
#ブロマスゲームラボ #Roblox #AI #ゲーム制作 #子ども向けプログラミング
#プログラミング教室 #ゲームクリエイター #さいたま #南与野 #与野本町
#教室運営 #月次振り返り
```

## 文章トーンのルール

- **塾のチラシ調にしない**。開発現場のライブ感、試行錯誤の正直さを大事にする
- 反省点も隠さず書く。「うまくいかなかった→こう改善する」の流れが信頼につながる
- 子どものエピソードは具体的に。「〇〇なお子さんが〇〇できた」が読者の心に刺さる
- 親御さん視点も意識する（35〜44歳、「消費より創造」を求める層）
- 締めは次回への予告または展望で終わる

## 書かないこと

- 個人が特定できる情報（名前・学校名など）
- 断定的な成果（「必ず〇〇になれます」系）
- 他の教室・サービスの名指し批判
