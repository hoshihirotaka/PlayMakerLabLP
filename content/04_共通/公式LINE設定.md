## 0. 無料プランの制約と、それを踏まえた設計方針

無料プラン（コミュニケーションプラン）は **配信メッセージが月200通まで**。
ここでいう200通は「延べ通数」なので、**友だち50人に一斉配信を1回送ると50通**を消費します（＝50人なら月4回が限界）。

一方で、**次の3つは通数にカウントされません**（＝実質無制限）。

| 機能 | 課金 | 使いどころ |
|---|---|---|
| **あいさつメッセージ** | 無料 | 友だち追加時に自動送信。**ここに情報を寄せるのが最重要** |
| **リッチメニュー** | 無料 | トーク画面下部に常時表示。いつでも見られる導線 |
| **1:1チャット** | 無料 | 個別のやり取り。個別プランの案内もここで送る |
| 一斉配信 | **200通/月** | イベント告知など、本当に必要なときだけ |

**設計方針**: 情報は「あいさつメッセージ」と「リッチメニュー」に置き、一斉配信は**月1〜2回のイベント告知に温存**する。

※プラン内容は変わることがあるので、実際の通数は管理画面でご確認ください。


## 0-b. 役割が変わりました（2026-09-08）

**これまで：リピーターと個別プランのテスト用。新規の受け皿として使わない。**
**これから：広告から来た「まだ日程を決めていない人」を受ける、新規のプール。**

同じ質問が繰り返されるので、変えた理由をここに書いておきます。

### なぜ変えたか

**日付を訴求する広告は、日付のあるページにしか着地できません。**

```
日付を訴求する    → Doorkeeperのイベントページしか行き先がない
サービスを訴求する → 日付のないページに着地できる（LINE・ホームページ）
```

これまでは日付の広告しか出していなかったため、**着地先を選ぶ余地がありませんでした。**

一方で、詰まっているのは**認知**です（リピートは横ばい、落ちているのは新規だけ）。
**認知の段階にいる人は、まだ日程を決めていません。**
その人たちを受ける場所が、どのチャネルにもありませんでした。

**LINEは「まだ日程を決めていないが興味はある人」の受け皿として使います。**

```
広告        認知
LINE        プール（誰が興味を持っているか）
Doorkeeper  申込と決済のページ（プールではない）
```

### 費用は増えません

**あいさつメッセージは無料・無制限**なので、何人来ても通数を消費しません。
上の表のとおり、通数を食うのは**一斉配信だけ**です。

日程の案内は `schedule.html` へのリンクで足ります（日付を持たないページなので腐りません）。
**あいさつメッセージに日付を焼き込まないこと。** 自動送信なので、
書き換えを忘れると古い情報が全員に届き続けます。

### ⚠️ 解消していない条件

旧方針には「**入口を広げる前に、誰がいつ返すかを決める必要がある**」という条件がありました。
**これはまだ解消していません。**

あいさつメッセージは自動なので返信は不要ですが、**1:1チャットに質問が来たら返す必要があります。**
**2026-09-08に「平日10時〜21時ごろ」で確定しました**（時間外の応答メッセージと一致させています）。

|---|---|---|

## 6. 友だち追加の導線

**友だち追加URL: 管理画面で発行された `https://lin.ee/...` をそのまま使う。**<br />（転送先 `https://line.me/R/ti/p/@361prjng` ／ LINE ID `@361prjng`。**これは確認用で、貼る先には使わない**）

### ⚠️ 短縮URL（lin.ee）は毎回変わります。ずれても間違いではありません

**管理画面でコピーするたびに、新しい `lin.ee/xxxxx` が発行されます。**
末尾の `ts` が発行日時なだけで、**飛び先は同じアカウントです。**

```
lin.ee/wfkk7Ik  → line.me/R/ti/p/@361prjng?oat_content=url&ts=08300807   （8/30 08:07 発行）
lin.ee/RkQ2pUy  → line.me/R/ti/p/@361prjng?ts=09081118&oat_content=url   （9/8 11:18 発行）
```

**記録と手元のURLが違っても、作業を止めないこと。** 2026-09-08に実際に確認しました。

**⚠️ 実際に使うのは短縮URL（`lin.ee/...`）のほう。**
`ts` と `oat_content=url` が付くので、**LINE側が流入経路を見ている可能性がある**（2026-09-08 本人の指摘）。
恒久形に置き換えると、その情報が落ちる。**発行された短縮URLをそのまま使うこと。**

`line.me/R/ti/p/@361prjng` は**中身を確かめるとき用**で、貼る先には使わない。

## LINEのインアプリブラウザでのアンカーリンクのズレ（2026-08-14 更新）

LPの「カリキュラム」セクションへのアンカーリンク（#curriculum）について、
LINEのインアプリブラウザ（LINE公式アカウントのリッチメニューから開いた場合）で
ジャンプ先の位置がずれる不具合が発生しています。

【現象】
- リッチメニューからカリキュラムへのリンクをタップすると、
  ページは開くがcurriculumセクションの位置までスクロールされない
  （表示位置がずれる）
- 通常のブラウザ（ハンバーガーメニュー経由で開いた場合等）では正常に動作する

【推測される原因】
LINEのインアプリブラウザでは、ページの画像やレイアウトの読み込みが
完了する前にアンカージャンプの処理が実行され、
後から読み込まれる要素で高さがずれることでスクロール位置がずれている可能性

【対応してほしいこと】
- 素の#curriculumアンカーリンクに依存するのではなく、
  ページの読み込み完了（画像等含む）を待ってから
  JavaScriptでcurriculumセクションへスクロールする処理に変更してほしい
- window.onloadやImagesLoaded的な仕組みを使うか、
  もしくは一定時間（例: 500ms〜1000ms）の遅延を入れてから
  scrollIntoViewする形でも構わない
- 修正後、LINEアプリ内から実際に動作確認したい

【対象ファイル】
LP本体（index.html）の該当箇所
