# SNSシェア文言ガイド（X・Threads・Facebook・Instagram）

note記事やイベントを各SNSでシェアするときの共通ルール。
個別の文言は `02_開催後作業/sns/`（開催回に紐づくもの）と `03_定期投稿/sns/`（コラムなど）に、
**1記事1ファイル**で置く。

- 記事の書き方 → [NOTE-GUIDE.md](NOTE-GUIDE.md)
- noteへの入稿手順 → [NOTE-EDITOR-AUTOMATION.md](NOTE-EDITOR-AUTOMATION.md)

---

## ファイル命名規則

```
sns-{対象記事のファイル名}.md
```

| 対象記事 | シェア文言の置き場所 |
|---|---|
| `02_開催後作業/note/note-session-11.md` | `02_開催後作業/sns/sns-note-session-11.md` |
| `03_定期投稿/note/note-column-01-*.md` | `03_定期投稿/sns/sns-note-column-01.md` |
| `03_定期投稿/note/note-monthly-2026-08.md` | `03_定期投稿/sns/sns-note-monthly-2026-08.md` |

1ファイルの中に「X / Threads / Facebook」「Instagram」の各セクションを持たせる。
1記事の告知作業が1ファイルで完結する形にする。

## Xの文字数の数え方（お手軽版を作るときの基準）

Xは**重み付き280**で判定する。「日本語140字」ではない点に注意。

- 日本語・絵文字 = **2**カウント
- 半角英数・記号・改行 = **1**カウント
- **URLは実際の長さに関係なく一律23カウント**（短縮する必要はない）

つまり `280 −（URL 23）= 257` が本文に使える枠。日本語だけなら**約128字**。

ハッシュタグは1つで20カウント前後を食う。X基準に収める版では**原則入れないか、1つまで**にする。
（例: `#ブロマスゲームラボ` = 19カウント）

### 文字数を数えるスクリプト

```python
def w(s, url_count=0):
    total = 0
    for ch in s:
        cp = ord(ch)
        if cp <= 4351 or 8192 <= cp <= 8205 or 8208 <= cp <= 8223 or 8242 <= cp <= 8247:
            total += 1   # ASCII・ラテン・改行
        else:
            total += 2   # 日本語・絵文字
    return total + url_count * 23

print(w(本文, 1), "/ 280")
```

## 媒体ごとの使い分け

| 媒体 | 文字数 | 方針 |
|---|---|---|
| X | 重み付き280 | ここに合わせれば他媒体にもそのまま貼れる |
| Threads | 500字 | Xと同文でOK。余裕があれば少し長めにしてもよい |
| Facebook | 実質制限なし | 地域コミュニティ・保護者層向けに、温かみのある長めの文体 |
| Instagram | — | フィードの本文には**URLが貼れない**ので「リンクはプロフィールから」で締める。**ストーリーズは例外**（下記） |

### Instagramでリンクを踏ませる唯一の経路：ストーリーズ＋ハイライト

「URLが貼れない」のは**フィードのキャプションだけ**。**ストーリーズのリンクステッカーは使える**
（かつての1万フォロワー条件は撤廃済み）。しかも**ハイライトに入れてもタップできる状態で残る**。

```
リール（フォロワー外に届く）
   ↓ プロフィールを踏む
「次回開催」ハイライト
   ↓ リンクステッカーをタップ
Doorkeeper（申込）
```

- **プロフィールに常設の申込導線を作れる。** 更新は、開催が決まったらストーリーズを1本上げて
  ハイライトに追加するだけ
- utmは `utm_source=instagram&utm_medium=story` を付ける
- リール視聴者の一定数がプロフィールを踏んでいる（比率はcurriculum側の計測を参照）。
  **その受け皿がないと、そこで止まる**

### お手軽版（画像を作らず、リンクだけ貼る運用）

X基準に収めた1本を作り、**X・Threads・Facebookに同じものをそのまま貼る**。
画像制作の工数をかけずに告知したいときに使う。個別ファイルには「X / Threads / Facebook 共通」として記載する。

## 運用ルール

- **URLは投稿直前に差し込む。** ファイル内では `[URL]` のまま置いておく（記事が下書きの段階では確定しないため）
- noteのURLは `https://note.com/shgame/n/{記事ID}` の形。公開後に実物を確認する
- Instagram単体の投稿ルール（作品集投稿など）は [02_開催後作業/instagram/README.md](../02_開催後作業/instagram/README.md) を参照
- タグは過去の投稿からそのままコピーせず、その記事の内容に合わせて選び直す
